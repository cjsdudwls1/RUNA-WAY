# 러너웨이 PRD v0.11

- 2026-09-10. 핵심만. 상세는 [부록](05-appendix.md), 동물 수치는 [04-animal-data.md](04-animal-data.md)
- 확정 결정: [02-decisions.md](02-decisions.md)

## 1. 정의

- 제품의 에고: 실감. 진짜 동물이 옆에서 달리는 느낌을 청각과 시각으로 동시에 느껴야 한다. 모든 기능 결정은 이 기준으로 거른다
- 앱 이름: 러너웨이
- 지도에 뜬 가상 동물을 피해, 제한 시간 안에 목적지를 찍고 출발점으로 돌아오는 러닝 게임
- 컨셉의 축은 현실성. 적의 속도, 지속 시간, 회복, 피로 전부 실측 데이터
- 훅: 내 위치와 적의 위치가 같은 지도에 뜬다
- 타깃: 전부. 걷는 사람은 티어 1~8, 러너는 티어 15 이상
- 플랫폼: 안드로이드. 카메라 AR 없음. 월 예산 5만원. 1인 개발

## 2. 세션

- 30분, 5km가 표준. 프리셋 1 / 3 / 5km
- 루프형: 출발점 → 목적지 1~3개 → 출발점 복귀. 귀가 문제 없음
- 목적지만 지정, 경로는 자유. 라우팅 API 없음
- 워밍업 3분 무적, 마지막 10~15% 쿨다운
- 잡힘: 위협 게이지. 30m 진입 시 상승, 50m 이탈 시 2배로 감소, 4초에 100%
- 피격 1회 = +30초 페널티 + 적 200m 후방 재배치. 3회면 실패. 러닝 기록은 항상 저장
- GPS 정확도 25m 초과 시 게이지 반속, 40m 초과 시 적 정지(냄새 잃음)
- 정지 8초면 자동 일시정지, 적도 정지. 신호등이 실력 차이가 되지 않게

## 3. 적

### 3.1 상태 머신

적은 플레이어 궤적을 따라 추격한다. 네 상태를 순환한다.

| 상태 | 속도 | 끝나는 조건 |
|---|---|---|
| 배회 | 순항 이하 | 감지 반경 진입 |
| 스프린트 | 그 사이클의 최고 속도 | 그 사이클의 지속 시간 소진 |
| 지침 | 순항의 40~60% | 회복 시간의 절반 경과 |
| 회복 | 순항 | 나머지 절반 경과. 다시 배회 또는 스프린트 |

### 3.2 피로 모델

사이클을 돌 때마다 적은 약해진다. 최고 속도와 지속은 줄고, 회복은 길어진다. 모든 동물에 적용.

```
사이클 n (0부터)
스프린트 속도(n) = 최고속도 x dv^n
스프린트 지속(n) = 기본지속 x dt^n
회복 시간(n)    = 기본회복 x g^n
```

- 동물별 계수 3개: dv(속도 감쇠), dt(지속 감쇠), g(회복 증가)
- 스프린터(치타, 그레이하운드, 고양이)는 감쇠가 크다. 지구력형(늑대, 진돗개)은 거의 없다
- 계수의 초깃값은 [04-animal-data.md](04-animal-data.md). M0에서 30분 평균이 실측치와 맞도록 보정

치타 예시:

| 사이클 | 스프린트 | 지속 | 지침 + 회복 |
|---|---|---|---|
| 1 | 114 km/h | 25초 | 3분 |
| 2 | 85 km/h | 18초 | 5분 |
| 3 | 64 km/h | 13초 | 8분 |
| 4 | 48 km/h | 9초 | 12분 |

- GPS 상에서 30초 빠르게 다가왔다가 몇 분 느려지는 패턴이 반복되고, 반복될수록 무뎌진다
- 적의 스프린트 = 사용자의 인터벌, 적의 회복 = 사용자의 회복. 동물의 생리가 곧 훈련 프로그램

### 3.3 티어 · 추격 시뮬레이션 기준

- 티어 순서 = 표준 러너(10 km/h, 5km, 잡음 없음) 추격 시뮬의 피격 횟수. 근거 [08-m0-findings.md](08-m0-findings.md)
- 30분 평균 순위와 추격 승패는 다르다. 감지 반경 안에서 스프린트 1회로 (감지 반경 - 30m)를 닫으면 잡힌다
- 30분 지속 속도는 도감 정보로만. "30분 레이스면 네가 이긴다. 근데 이건 추격이다"
- 트랙 A 정규(순차 해금, 10 km/h에서 피격 2회 이하) 15종: 세발가락나무늘보 → 늘보로리스 → 힐라몬스터 → 닭 → 치와와 → 나일악어 → 코모도왕도마뱀 → 다람쥐 → 코알라 → 집고양이 → 돼지 → 아홉띠아르마딜로 → 하마 → 코끼리 → 그레이하운드
- 트랙 B 못 깨는 것들(상시 개방, 3회 이상) 10종: 붉은캥거루, 치타, 유럽산토끼, 회색늑대, 진돗개, 지구력경주마, 단봉낙타, 알래스칸허스키, 타조, 프롱혼. 생존 시간만 기록
- 러너가 13 km/h면 캥거루는 1피격. 러너 속도에 따라 경계가 움직이는 것을 도감에 표시
- 파라미터와 출처: [04-animal-data.md](04-animal-data.md), `sim/data/animals.json`

## 4. 화면과 소리

### 지도

- 화면 켜짐 기본. 무조작 15초 후 디밍, 적 접근 시 복귀. 배터리 30분 8% 이하
- 정보 위계: 위협 게이지 > 적 방향·거리 > 목적지 방향·거리 > 시간·페이스
- 적은 점이 아니라 위협 반경 원. 상태별로 색과 크기가 바뀐다
- 적의 체력은 화면에 표시하지 않는다. 지침은 소리(헐떡임, 쉰 포효)로만 전달

| 상태 | 아이콘 | 원 | 잔상 |
|---|---|---|---|
| 배회 | 흐릿, 회색 | 없음 | 없음 |
| 스프린트 | 선명, 빨강 | 최대 | 길게 |
| 지침 | 주황, 헐떡임 | 축소 | 짧게 |
| 회복 | 반투명 | 없음 | 없음 |

### 소리

화면을 보지 않아도 적의 상태와 거리를 안다.

| 상태 | 근접 60m | 중간 60~150m | 원거리 150m+ |
|---|---|---|---|
| 배회 | 킁킁 탐색음 | 발소리 | 무음 |
| 스프린트 | 포효 + 발소리 최대 + BGM 템포 최고 | 포효 | 멀리서 울음 |
| 지침 | 헐떡임, 힘 빠진 울음 | 거친 숨 | 희미한 숨 |
| 회복 | 낮은 그르렁 | 거의 무음 | 무음 |

- 접근 시 음량·피치 상승, 이탈 시 하강 + 로우패스
- 사이클이 거듭될수록 포효는 약해지고 헐떡임은 길어진다. 피로 모델이 소리에도 적용
- 음성은 사전 생성 뱅크, 오퍼레이터 1인. 실시간 TTS 없음
- 배경음악: 서식지별 야생 앰비언스 + 추격 시 템포 올라가는 드럼 레이어. 로열티프리 또는 CC0 소재로 시작
- 세션 시작에 두 수치를 나란히: "치타 · 스프린트 114 km/h · 30분 기준 4.5 km/h"

### 연출 · 테마파크처럼

현실성이 컨셉이라면 연출은 그 현장을 데려다 놓는 일이다. 어트랙션 탑승 같은 30분.

- 서식지 사운드스케이프: 티어마다 앰비언스가 바뀐다. 나무늘보·악어는 열대우림과 강가, 치타·프롱혼은 초원, 늑대는 침엽수림, 진돗개는 한국 시골 밤. 실제 서식지 환경음
- 톤은 어트랙션. 오퍼레이터가 게임마스터처럼 과장되게 긴박감을 연출한다
- 오프닝 브리핑 20~30초: 오퍼레이터가 상황을 설정한다. "여기는 세렝게티 남부. 300m 뒤 풀숲에 치타 한 마리. 아직 당신을 못 봤다. 3, 2, 1"
- 점프 스케어: 감지 반경 진입 순간 큰 포효 + 강한 햅틱 + BGM 급전환. 세션당 1~2회로 제한해 무뎌지지 않게
- 피로가 쌓이면 연출도 약해진다. 4번째 포효는 쉰 소리
- 도착 연출: 목적지 도달 시 "안전지대" 사운드 전환. 새소리, 바람, 심박 BGM 정지
- 가벼운 스토리: 티어 1(아마존)에서 티어 19(한국)까지 세계를 건너는 여정. 티어 시작마다 도입 1편, 클리어마다 마무리 1편. 본편 미션 서사는 MVP 제외
- 안전 규칙: 점프 스케어는 횡단보도·차도 30m 이내에서 금지, 볼륨 상한 적용, 야간은 강도 하향

## 5. MVP 범위

### 포함

- 안드로이드 단독
- 지도에 내 위치 + 적 1~2마리, 상태 머신 + 피로 모델
- 루프형 목적지 자동 생성, 위협 게이지, 피격 3회
- 트랙 A 19종 + 트랙 B 6종 파라미터. 아트는 실루엣 1종씩
- 사전 생성 오디오 150개 + 서식지 앰비언스 5종 + 오프닝 브리핑 템플릿 + 동물별 점프 스케어 1종
- 결과 화면 + 정적 공유 카드
- Health Connect 워크아웃 쓰기

### 제외

- 카메라 AR, 워치, 글래스, iOS
- 리더보드, 서버, 로그인 (사용자 늘면 도입)
- 실시간 멀티, 크루, 고스트, 채팅
- 실시간 TTS, 스토리, 시즌패스, 결제, 트레드밀

## 6. 기술

| 영역 | 선택 | 월 비용 |
|---|---|---|
| 앱 | Kotlin + Jetpack Compose | 0 |
| 지도 | 카카오맵 SDK, 추상화 레이어 경유 | 0 (첫 활성 앱 무료) |
| 위치 | FusedLocation + Foreground Service | 0 |
| 오디오 | Oboe 네이티브 | 0 |
| 시뮬레이션 | 순수 Kotlin 모듈, 고정 틱 1Hz, 정수 연산 | 0 |
| 백엔드 | 없음. 전부 온디바이스 | 0 |
| 분석 | Sentry 무료 티어 (크래시만) | 0 |

- 시뮬레이션 코어는 결정론. 세션 시드를 저장해 나중에 서버 리플레이 검증이 가능하게
- MVP는 서버 없음. 기록은 폰에만. 위치 데이터가 밖으로 나가지 않음
- 세션 로직과 오디오는 완전 오프라인. 지도만 온라인
