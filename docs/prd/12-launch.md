# 출시와 알리기

원칙: 30%만 완성해 일단 던지고, 만든 시간만큼 알리는 데 쓴다.

## 2026-09-24 출시 판정

- 웹(링크) 출시: 가능. `web/deploy.sh` 한 번이면 gh-pages에 반영된다
- 플레이 스토어: 코드는 준비됨. 정책상 비공개 테스트 12명 × 14일이 먼저다(13-playstore.md). 오늘 할 수 있는 건 테스트 트랙 시작까지

통과한 것 (헤드리스 크롬, web/qa.mjs)

| 항목 | 결과 |
|---|---|
| 스크립트 오류 | 0 (로드, 실내 데모 완주, GPS 모드, 소리 테스트) |
| 음성 팩 | 관제 204조각 + 동물 100조각 전부 디코드. 대사 키 누락 0 |
| 구운 음성 재생 | 브라우저 기계음 호출 0회. 동물 목소리 재생 |
| 느린 망 | 팩이 2.5초 늦게 와도 첫 말부터 구운 음성 |
| 팩 차단 | 브라우저 TTS로 대체, 멈춤 없음 |
| 지도 | 끌기, 확대, '내 위치로' 복귀 |
| GPS 모드 | 45초 135m 이동 → 0.12 km 표시. 페이스 정상 |
| 결과 화면 | 공유 카드 그려짐 |
| 기존 테스트 | 골든 테스트(코어 일치), 시뮬 테스트 16개 |

이번에 고친 결함

- 실내 데모에서 내 속도가 NaN으로 표시. 리플레이 좌표에 속도 필드가 없었다

헤드리스로 못 보는 것 (출시 후 첫 주에 본인이 확인)

- 실외 1 km. 아래 "출시 전 단 하나의 조건" 표 그대로
- 이어폰으로 음성 청취. 다급한지, 동물 목소리가 웃긴지, 바람 속에서 들리는지
- 화면 끈 상태에서 음성이 계속 나오는지

## 현재 진단

이 프로젝트는 이미 과잉 개발 쪽에 있다.

- 결정론적 코어를 파이썬, 코틀린, 자바스크립트 3개 언어로 포팅하고 골든 테스트로 일치를 증명했다
- 동물 25종의 실측 데이터, 피로 모델, 상태 머신, 오디오 공간화, 발화 스케줄러
- 그런데 **실제 밖에서 끝까지 돌아본 세션이 0회**이고, **사용자 본인 말고 아는 사람이 0명**이다

만든 것의 문제가 아니라 순서의 문제다. 지금부터는 더하지 않고 덜어내고 알린다.

## 출시 전 단 하나의 조건

**한 번이라도 밖에서 끝까지 도는 주행.**

- 좌표 폭주를 고친 뒤 실주행 검증이 0회다
- 값이 틀린 상태로 사람을 부르면 채널이 한 번에 탄다. 첫인상은 다시 안 온다
- 이 한 번이 나오기 전에는 어떤 홍보도 하지 않는다

확인할 것 (1 km면 충분)

| 항목 | 통과 기준 |
|---|---|
| 거리 | 실제 뛴 거리와 10% 안 |
| 방향 | 서 있을 때 지도가 안 돈다 |
| 지도 | 타일이 뜬다. 워터마크 없음 |
| 소리 | 적이 왼쪽에 있으면 왼쪽에서 들린다 |
| 말 | 거슬리지 않는다 |
| 배터리 | 30분에 몇 % 빠지는지 숫자로 |

## 지금 덜어낸 것

- 홈 화면을 버튼 하나로. 설정 9개는 접기 안으로
- 처음 오는 사람은 "도망치기" 하나만 누르면 된다. 기본값 닭, 3 km, 3마리

## 지금 붙인 것 (알리기용)

- 결과 이미지 공유. 러닝 게임은 결과 스크린샷으로 퍼진다. 그게 유일한 성장 고리다
- OG 이미지와 설명. 카카오톡에 링크를 붙이면 미리보기가 뜬다
- PWA 매니페스트. 홈 화면에 추가하면 앱처럼 열린다. 설치 마찰 0
- 방문자 집계 훅. `web/build.py`의 `COUNTER`에 goatcounter 코드만 넣으면 켜진다. 무료

## 첫 주 계획

순서가 중요하다. 위에서부터.

| 순서 | 할 일 | 목표 |
|---|---|---|
| 1 | 혼자 1 km 실주행. 위 표 6개 확인 | 통과 |
| 2 | 친구 5명에게 직접 링크. 옆에서 보며 시킨다 | 5명 중 3명이 끝까지 |
| 3 | 경복대 에브리타임, 학교 러닝 동아리 | 첫 외부 사용자 |
| 4 | 러닝 커뮤니티 (네이버 카페 런너스클럽, 마라톤 온라인) | 러너 반응 |
| 5 | GeekNews(news.hada.io), 클리앙 모두의공원 | 개발자 반응 |
| 6 | 레딧 r/SideProject, r/running | 영어권 반응 |

2번이 가장 중요하다. 옆에서 보면 어디서 막히는지 5분 만에 다 나온다. 100명한테 링크 뿌리는 것보다 낫다.

## 반응이 없으면

- 2번에서 3명이 끝까지 못 가면 제품 문제다. 홍보를 늘리지 말고 그 지점을 고친다
- 3~5번을 다 돌았는데 일주일 재방문이 0이면 접고 다음으로 넘어간다
- 재방문이 나오면 그때 완성도를 올린다. 실제 동물 음원, 도로망 추종, 리더보드
