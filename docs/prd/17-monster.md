# 몬스터 추가 (기획 토의 초안)

- 2026-09-25. 사용자 제안: 동물은 그대로 두고 몬스터를 새 범주로 추가
- 상태: 1차 구현 (2026-09-25). 소리 파일(괴성, 대사, 배경음악)은 사용자 로컬에서 생성 중
- 확정: 게임 같은 괴물, 적응형 속도, 괴성 + 대사, 지속주(저승사자)와 인터벌(도깨비)

## 1차 구현

| 괴물 | 훈련 | 속도 규칙 | 대사 |
|---|---|---|---|
| 저승사자 | 지속주 | 내 페이스 ×1.0 등속. 지치지 않는다. 늦추면 붙는다 | 느리고 차갑게. "멈추면… 데려간다." |
| 도깨비 | 인터벌 | 평소 내 페이스 ×0.9로 따라오다 80m 안이면 ×1.6으로 30초 돌진, 쉬는 시간 약 2분 | 호통. "네 이노오옴!!!" |

- 내 페이스: 워밍업(없으면 첫 60초) 동안 달린 속도의 중앙값. 걷거나 멈춘 초는 뺀다. 5~18km/h로 제한. 재기 전엔 8km/h
- 대사 사건: 발견, 돌진, 코앞(40m 안), 잡음, 지침·멀어짐, 도발(40~160m에서 가끔). 사건마다 쿨다운
- 잡히면 괴물 대사가 먼저, 1.8초 뒤 관제 "한 번 잡혔다!"
- 괴성 녹음이 없으면 합성 괴성(낮은 톱니 포효). 대사 녹음이 없으면 대사는 안 나온다
- 화면: 홈에서 "동물 사파리 / 괴물 추격" 탭. 모드마다 색, 글꼴, 일러스트(SVG), 문구, 배경음악
- 검증: web/qa.mjs 10번. 리플레이 9.5km/h → 도깨비 돌진 15km/h, 저승사자 등속 9.5km/h

## 왜 몬스터인가

| | 동물 | 몬스터 |
|---|---|---|
| 속도 | 실측 그대로. 바꾸면 컨셉이 깨진다 | 마음대로. 러너에게 맞출 수 있다 |
| 난이도 | 닭은 너무 쉽고 치타는 못 깬다. 중간이 러너마다 다르다 | 러너 페이스에 맞춰 늘 "조금 버거운" 수준 |
| 소리 | 실제 녹음. 무섭진 않다 | 대사, 괴성, 속삭임으로 공포 |
| 운동 효과 | 동물 성질대로 | 인터벌 훈련을 설계할 수 있다 |

- 핵심 가치는 공포보다 **적응형 속도**다. 동물이 못 푸는 "누구에게나 적당히 어려운" 문제를 푼다

## 몬스터 후보 (처음 3종)

| 이름(가제) | 움직임 | 러너가 겪는 것 |
|---|---|---|
| 그림자 | 러너 최근 평균 페이스 - 0.3km/h로 쉬지 않고 따라온다. 돌진 없음 | 페이스를 떨어뜨리면 잡힌다. 지속주 훈련 |
| 사냥꾼 | 평소엔 멀리서 따라오다 러너 평균 x 1.3으로 30초 돌진, 90초 쉼 | 인터벌 훈련. 돌진을 버티면 벌어진다 |
| 속삭이는 것 | 느리지만 소리가 가까워질수록 대사가 늘어난다. 잡혀도 페널티 대신 공포 연출 | 입문용. 공포 체험 중심 |

- 속도 기준: 워밍업 2분의 평균 페이스로 시작, 이후 최근 3분 이동 평균으로 천천히 따라간다
- 동물과 같은 엔진을 쓴다. 상태 머신(배회, 돌진, 지침, 회복)과 판정은 그대로, 속도 값만 러너에게서 온다

## 소리 만들기

몬스터 소리는 두 종류로 나눠야 도구가 맞는다.

### 1. 대사 (말)

| 도구 | 한국어 | 목소리 설계 | 라이선스 | 판단 |
|---|---|---|---|---|
| Qwen3-TTS VoiceDesign 1.7B | 지원 | 글로 목소리를 묘사해 만든다("쉰 목소리의 늙은 남자, 속삭임") | Apache-2.0 | 1순위. 사용자 제안 그대로 |
| Qwen3-TTS Base + 음성 복제 | 지원 | 참고 음성 3초로 복제 | Apache-2.0 | 원하는 목소리를 직접 녹음해 쓸 때 |
| Supertonic 3 (지금 관제 음성) | 지원 | 고정 10종, 감정 제어 없음 | OpenRAIL-M | 무서운 연기는 못 한다 |
| Chatterbox Multilingual | 지원 | 과장도(exaggeration) 조절 | MIT | 2순위. 감정 과장이 된다 |
| ElevenLabs Voice Design | 지원 | 최고 품질 | 유료 | 월 0원 원칙과 충돌 |

- 어느 TTS든 날것으로는 "사람이 무섭게 연기한 소리"다. 몬스터처럼 들리게 하는 건 후처리다
  - 피치 3~5반음 내리기, 포먼트 이동(목이 커 보이게), 약한 디스토션, 저역 강조, 두 테이크 겹치기(한 목에서 두 소리)
  - ffmpeg rubberband와 이미 쓰는 굽기 도구(web/voice/bake.py)로 된다
- GPU가 필요하다(1.7B). 이 개발 환경은 CPU뿐이라 사용자 로컬에서 굽는 게 맞다. 동물 녹음처럼 로컬 Claude Code에 맡긴다

### 2. 울음, 괴성 (말이 아닌 소리)

| 방법 | 판단 |
|---|---|
| 실제 동물 녹음 가공 (CC0 사자, 곰, 돼지 비명을 겹쳐 피치 내리고 역재생 등) | 1순위. 영화 괴물 소리 만드는 표준 방식. 이미 녹음 수집 경로가 있다 |
| Stable Audio Open 1.0 (텍스트로 효과음 생성) | 2순위. 연매출 100만 달러 미만 상업 이용 가능. 품질 들쭉날쭉 |
| TTS로 괴성 | 비추천. 말 모델이라 비명, 으르렁을 못 만든다 |

## 안전

- 달리는 중 점프 스케어는 사고 위험이다. 갑자기 큰 소리는 쓰지 않는다. 공포는 "점점 가까워지는 소리"로 만든다
- 최대 음량은 지금 동물 소리와 같게 묶는다
- 첫 선택 때 "공포 요소가 있다" 한 줄 고지

## 사용자에게 물을 것

1. 톤: 진짜 공포(속삭임, 숨소리) vs 게임 같은 괴물(으르렁, 과장)
2. 적응형 속도: 러너에게 맞추기 vs 고정 난이도 단계(쉬움, 보통, 어려움)
3. 대사 양: 거리별 짧은 한마디 vs 거의 없음(괴성 위주)
4. 처음 몇 종: 위 3종으로 시작할지

## 순서 (정해지면)

1. 엔진: 동물 데이터 대신 "속도 규칙"을 받는 몬스터 타입. 적응형 속도
2. 소리: 로컬 Claude Code용 프롬프트 (괴성은 녹음 가공, 대사는 Qwen3-TTS VoiceDesign)
3. 화면: 홈에 동물 / 몬스터 탭
4. QA: 적응형 속도가 러너 페이스를 따라가는지 리플레이로 검증
