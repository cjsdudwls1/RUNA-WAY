# 몬스터 추가 (기획 토의 초안)

- 2026-09-25. 사용자 제안: 동물은 그대로 두고 몬스터를 새 범주로 추가
- 상태: 1차 구현 (2026-09-25). 소리 파일(괴성, 대사, 배경음악)은 사용자 로컬에서 생성 중
- 확정: 게임 같은 괴물, 적응형 속도, 괴성 + 대사, 지속주(저승사자)와 인터벌(도깨비)

## 1차 구현

| 괴물 | 훈련 | 속도 규칙 | 대사 |
|---|---|---|---|
| 저승사자 | 지속주 | 내 페이스 ×1.0 등속. 지치지 않는다. 늦추면 붙는다 | 느리고 차갑게. "멈추면… 데려간다." |
| 도깨비 | 인터벌 | 평소 내 페이스 ×0.9로 따라오다 80m 안이면 ×1.6으로 30초 돌진, 쉬는 시간 약 2분 | 호통. "네 이노오옴!!!" |

- 내 페이스: 워밍업(없으면 첫 60초) 동안 달린 속도의 중앙값. 걷거나 멈춘 초는 뺀다. 5~18km/h로 제한. 재기 전엔 8km/h
- 대사 사건: 발견, 돌진, 코앞(40m 안), 잡음, 지침·멀어짐, 도발(40~160m에서 가끔). 사건마다 쿨다운
- 잡히면 괴물 대사가 먼저, 1.8초 뒤 관제 "한 번 잡혔다!"
- 괴성 녹음이 없으면 합성 괴성(낮은 톱니 포효). 대사 녹음이 없으면 대사는 안 나온다
- 화면: 홈에서 "동물 사파리 / 괴물 추격" 탭. 모드마다 색, 글꼴, 일러스트(SVG), 문구, 배경음악
- 검증: web/qa.mjs 10번. 리플레이 9.5km/h → 도깨비 돌진 15km/h, 저승사자 등속 9.5km/h

## 왜 몬스터인가

| | 동물 | 몬스터 |
|---|---|---|
| 속도 | 실측 그대로. 바꾸면 컨셉이 깨진다 | 마음대로. 러너에게 맞출 수 있다 |
| 난이도 | 닭은 너무 쉽고 치타는 못 깬다. 중간이 러너마다 다르다 | 러너 페이스에 맞춰 늘 "조금 버거운" 수준 |
| 소리 | 실제 녹음. 무섭진 않다 | 대사, 괴성, 속삭임으로 공포 |
| 운동 효과 | 동물 성질대로 | 인터벌 훈련을 설계할 수 있다 |

- 핵심 가치는 공포보다 **적응형 속도**다. 동물이 못 푸는 "누구에게나 적당히 어려운" 문제를 푼다

## 몬스터 후보 (처음 3종)

| 이름(가제) | 움직임 | 러너가 겪는 것 |
|---|---|---|
| 그림자 | 러너 최근 평균 페이스 - 0.3km/h로 쉬지 않고 따라온다. 돌진 없음 | 페이스를 떨어뜨리면 잡힌다. 지속주 훈련 |
| 사냥꾼 | 평소엔 멀리서 따라오다 러너 평균 x 1.3으로 30초 돌진, 90초 쉼 | 인터벌 훈련. 돌진을 버티면 벌어진다 |
| 속삭이는 것 | 느리지만 소리가 가까워질수록 대사가 늘어난다. 잡혀도 페널티 대신 공포 연출 | 입문용. 공포 체험 중심 |

- 속도 기준: 워밍업 2분의 평균 페이스로 시작, 이후 최근 3분 이동 평균으로 천천히 따라간다
- 동물과 같은 엔진을 쓴다. 상태 머신(배회, 돌진, 지침, 회복)과 판정은 그대로, 속도 값만 러너에게서 온다

## 소리 만들기

몬스터 소리는 두 종류로 나눠야 도구가 맞는다.

### 1. 대사 (말)

| 도구 | 한국어 | 목소리 설계 | 라이선스 | 판단 |
|---|---|---|---|---|
| Qwen3-TTS VoiceDesign 1.7B | 지원 | 글로 목소리를 묘사해 만든다("쉰 목소리의 늙은 남자, 속삭임") | Apache-2.0 | 1순위. 사용자 제안 그대로 |
| Qwen3-TTS Base + 음성 복제 | 지원 | 참고 음성 3초로 복제 | Apache-2.0 | 원하는 목소리를 직접 녹음해 쓸 때 |
| Supertonic 3 (지금 관제 음성) | 지원 | 고정 10종, 감정 제어 없음 | OpenRAIL-M | 무서운 연기는 못 한다 |
| Chatterbox Multilingual | 지원 | 과장도(exaggeration) 조절 | MIT | 2순위. 감정 과장이 된다 |
| ElevenLabs Voice Design | 지원 | 최고 품질 | 유료 | 월 0원 원칙과 충돌 |

- 어느 TTS든 날것으로는 "사람이 무섭게 연기한 소리"다. 몬스터처럼 들리게 하는 건 후처리다
  - 피치 3~5반음 내리기, 포먼트 이동(목이 커 보이게), 약한 디스토션, 저역 강조, 두 테이크 겹치기(한 목에서 두 소리)
  - ffmpeg rubberband와 이미 쓰는 굽기 도구(web/voice/bake.py)로 된다
- GPU가 필요하다(1.7B). 이 개발 환경은 CPU뿐이라 사용자 로컬에서 굽는 게 맞다. 동물 녹음처럼 로컬 Claude Code에 맡긴다

### 2. 울음, 괴성 (말이 아닌 소리)

| 방법 | 판단 |
|---|---|
| 실제 동물 녹음 가공 (CC0 사자, 곰, 돼지 비명을 겹쳐 피치 내리고 역재생 등) | 1순위. 영화 괴물 소리 만드는 표준 방식. 이미 녹음 수집 경로가 있다 |
| Stable Audio Open 1.0 (텍스트로 효과음 생성) | 2순위. 연매출 100만 달러 미만 상업 이용 가능. 품질 들쭉날쭉 |
| TTS로 괴성 | 비추천. 말 모델이라 비명, 으르렁을 못 만든다 |

## 안전

- 달리는 중 점프 스케어는 사고 위험이다. 갑자기 큰 소리는 쓰지 않는다. 공포는 "점점 가까워지는 소리"로 만든다
- 최대 음량은 지금 동물 소리와 같게 묶는다
- 첫 선택 때 "공포 요소가 있다" 한 줄 고지

## 사용자에게 물을 것

1. 톤: 진짜 공포(속삭임, 숨소리) vs 게임 같은 괴물(으르렁, 과장)
2. 적응형 속도: 러너에게 맞추기 vs 고정 난이도 단계(쉬움, 보통, 어려움)
3. 대사 양: 거리별 짧은 한마디 vs 거의 없음(괴성 위주)
4. 처음 몇 종: 위 3종으로 시작할지

## 순서 (정해지면)

1. 엔진: 동물 데이터 대신 "속도 규칙"을 받는 몬스터 타입. 적응형 속도
2. 소리: 로컬 Claude Code용 프롬프트 (괴성은 녹음 가공, 대사는 Qwen3-TTS VoiceDesign)
3. 화면: 홈에 동물 / 몬스터 탭
4. QA: 적응형 속도가 러너 페이스를 따라가는지 리플레이로 검증

## 소리 파일 반영 (2026-09-26)

- 로컬 생성분: 대사 24(Qwen3-TTS VoiceDesign), 괴성 8 + 도깨비 발소리 4(CC0 녹음 가공), 배경음악 4곡(ACE-Step, 각 60~68초)
- 발소리(step): 로컬 작업이 제안. 괴물 속도에 맞춰 걸음 간격을 정한다(보폭 약 2.2m, 초당 0.8~3.5걸음). 4개를 돌려 쓴다
- 대사 ASR 역검증: 후처리 피치를 되돌려도 24개 중 12개가 CER 0.5 이상. 외침·속삭임 연기와 괴물 후처리는 ASR이 원래 약하다. 사람 귀 확인 필요

| 확인할 대사 (ASR이 거의 못 읽음) |
|---|
| 도깨비: 네 이노오옴!!!, 게 섰거라아!!, 코앞이다 이놈!, 으하하하! 잡았다!, 혼쭐이 나 봐라!, 금 나와라 뚝딱! |
| 저승사자: …찾았다., 숨소리가… 들린다., 가자… 저승으로., 도망쳐도… 소용없다., 언젠가는… 따라잡는다., 거기… 서거라… |

## 저승사자 대사가 "도망쳐도… 소용없다"뿐이던 버그 (2026-09-26)

- 사용자 보고: 저승사자 대사가 "도망쳐도… 소용없다. / 언젠가는… 따라잡는다."만 들린다
- 의도 아님. 이 둘은 멀어짐(escape) 대사다. 150m 밖에서만 나온다
- 원인 세 겹
  - 시작 거리 2배(치타 피드백)로 300~460m 뒤에서 출발
  - 등속 괴물은 "뒤처지면 따라잡기"에서 빠져 있었다. 내 페이스 ×1.0이라 거리가 영영 안 준다
  - 워밍업 접근도 못 받았다. 코어 상태 머신이 등속 괴물에겐 늘 순항 속도(재기 전 시속 7.9km)를 준다. 워밍업 2분 내내 440~470m에 머물렀다
- 조치(앱 쪽만. 코어와 golden은 그대로)
  - 워밍업 동안 등속 괴물도 접근 속도를 받는다. 상한 초속 8m. 워밍업이 끝날 때 50m 뒤
  - 워밍업 뒤 감지 밖이면 러너 + 초속 1.5m로 따라온다(등속 괴물만 상한 없음. 도깨비는 전력 85% 상한 그대로)
  - 저승사자 감지 100m → 70m. 워밍업이 끝나면 약 50m 뒤에서 같은 속도로 붙는다. 도발(40~160m), 코앞(40m 안) 대사가 나온다
- 남은 설계 문제: ×1.0 등속이면 페이스를 지키는 한 영영 안 잡힌다. 페이스 설정 토의로(아래)
- 결과(리플레이 9.8km/h, 워밍업 2분): 2:00에 50m, 이후 45~67m 유지. 대사는 도발만. 워밍업 없음: 65~69m
- 검증: web/qa.mjs 12번. 실제 대사 파일로 워밍업 뒤 거리 120m 이하, 안 잡혔는데 멀어짐 대사가 나오면 실패
- 결과 화면: 저승사자는 돌진이 없어 잡혀도 "끝내 널 따라잡지 못했다"로 나오던 문구 수정. 공유 카드도 "등속 추격"

## 괴물 페이스 설정 (토의 중, 2026-09-26)

- 사용자 제기: 저승사자 ×1.0이면 평생 안 잡힌다. 실력이 늘어도 기준이 매번 워밍업으로 리셋된다. 단계, 속도 지정, 훈련 모드 중 무엇으로 할지. 기록을 저장해 점진적 과부하
- 진단: 괴물 배수(×1.0)가 아니라 기준이 문제. 워밍업 중앙값은 원래 느리다
- 설계 워크플로(제안 4관점 → 심사 3관점 → 종합) 결과

| 안 | 방식 | 고르는 것 | 장점 | 단점 |
|---|---|---|---|---|
| 1 (권고) | 목표 페이스 T 한 줄 + 자동 추천 | 괴물(=훈련 종류), T를 ±5초 | 요구 3개(속도 지정, 기록, 과부하)를 최소 변경으로. 코어 그대로 | 이지·회복 처방 없음. 분/km가 초보에게 낯섦 |
| 2 | 훈련 처방(역치 페이스 기준 존) | 편하게/지속주/템포/인터벌/반복 카드 | 실제로 강해지는 구조, 80/20, 부상 안전장치 | 구현 최대(코어·golden 수정), 워밍업 10분 |
| 3 | 명부 계급제 18단계 | 괴물만. 단계는 자동 승급·강등 | 게임 동기 최강 | 매 판 한계 강도, 단계당 1.5%가 실제 향상보다 빨라 정체·좌절 |

### 권고안 1의 규칙 (초안)

- 저승사자: T 페이스 등속. 감지 70m → 90m. 앞서 나가도 90m에서 따라붙는다
  - 6'00" 기준 잡히기까지: 5% 느리면 약 5분, 10% 느리면 약 2.7분, 조깅 7'30"면 약 1.3분
- 도깨비: 돌진 때 버텨야 할 페이스 I = T 속도 ×1.15. 돌진 속도 = I + (돌진 시작 간격 − 30m) ÷ 26초
  - 지금 ×1.6은 80m에서 출발해도 35m에서 멈춘다. 가만히 있어도 거의 안 맞는다
- 거리 환산: T는 5km 기준. 표시 페이스 = T × (거리/5)^0.06 (1km ×0.91, 10km ×1.04). 자유달리기는 5km 값
- 첫 달리기: 워밍업 중앙값 ×1.05, 연습판(진행 반영 없음). 이 판의 이동 페이스 중앙값이 첫 T
- 진행: 무피격 완주 2연속이면 5초 빠르게, 실패면 10초 늦게, 주당 5초 상한, 14일 넘게 쉬면 주당 5초 늦춤(최대 20초)
- 직접 넣은 값이 항상 우선. 자동값은 결과 화면에 "다음 추천"으로만
- 저장: rw.mpace(괴물별 T, I, 쉬는 시간, 연속 성공), rw.runs 50 → 200회(목표·실제 페이스, 1분 스플릿, 피격, 체감). JSON 내보내기

### 사용자에게 물을 것

1. 홈에 분/km 숫자를 보여 줄지, "편하게 / 조금 힘들게 / 힘들게" 말로만 보여 줄지
2. 괴물 모드에 거의 안 잡히는 "편하게"를 넣을지, 이지런은 동물 모드가 맡을지
3. 계급(승급·강등 음성)과 1km마다 페이스 읽어 주기를 넣을지. 넣으면 Qwen3-TTS 녹음 목록에 추가
