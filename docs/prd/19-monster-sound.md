# 괴물런 소리 설계

- 2026-09-27 초안. 규칙은 [18-monster-run.md](18-monster-run.md)
- 정하는 것: 언제 무슨 소리·대사·내레이션이 나오는지, 몇 개가 필요한지, 무엇으로 만드는지

## 1. 원칙

- 소리가 화면이다. 안 보고도 판세를 안다
- 판세는 세 겹으로 전한다: 거리감(크기·먹먹함·잔향), 방향(좌우, 앞뒤는 음색), 말
- 앞뒤는 말이 확정한다. 경주에서 괴물이 뒤면 비굴, 앞이면 놀림
- 말은 사건이 있을 때만. 공포는 침묵이 무기
- 반복은 몰입을 깬다. 한 상황의 대사를 다 쓸 때까지 같은 대사를 다시 안 쓴다(판을 넘어 기억)
- 공포는 크기보다 대비. 점프 스케어는 잡힐 때만
- 금지: 훈계와 착한 척(예: "신호 지키는 거 멋있다"), 욕설, 자해·자살 연상, 외국 억양 흉내, 외모 비하, 성적 묘사

## 2. 소리 층

| 층 | 내용 | 위치 | 규칙 |
|---|---|---|---|
| 배경 | 모드·괴물별 분위기 루프 | 스테레오 | 말이 나오면 8dB 낮춘다 |
| 괴물 몸 | 발소리, 숨, 움직임 루프 | 입체(괴물 위치) | 괴물 속도에 맞춰 발 간격 |
| 괴물 표식 | 방울, 방망이, 가위 같은 짧은 소리 | 입체 | 소리만 듣고 어떤 괴물인지 안다 |
| 괴물 대사 | | 입체. 5m 안이면 귀 옆 | |
| 내레이션 | 캐스터, 낭독자 | 가운데, 잔향 없음 | |
| 사건 효과음 | 추월, 발견, 잡힘, 닭 울음 | 사건마다 | |
| 심장 | 공포 전용 | 가운데, 낮게 | 격차가 줄면 빨라진다 |

- 말은 한 번에 하나
- 우선순위: 잡힘 > 발견·추월 > 괴물 대사 > 내레이션 > 1km 알림
- 말 사이 최소 3.5초(지금 규칙). 분당 상한은 경주 6마디, 공포 4마디

## 3. 거리 표현

| 구간 | 격차 | 소리 | 공포 | 경주 |
|---|---|---|---|---|
| 아득 | 150~200m | 아주 작게, 잔향 많이, 먹먹 | 가끔 먼 기척 | 한참 차이 |
| 멀리 | 80~150m | 작게 | 발소리가 들린다 | 한참 차이 |
| 다가옴 | 40~80m | 중간 | 심장 시작 | 차이 |

| 바로 뒤 | 5~15m | 귀 옆, 잔향 없음 | 속삭임 | 박빙 |
| 잡힘 | 5m에서 3초 | | 점프 스케어 | 없음 |

- 크기: 거리가 두 배면 약 5dB 작게(지금 규칙)
- 경주에서 괴물이 앞이면 소리를 조금 밝게, 뒤면 먹먹하게. 말로 확정한다

## 7. 괴물 소리 카드

| 괴물 | 성격 | 경주 목소리(귀엽게) | 공포 목소리(무섭게) | 부르는 말 |
|---|---|---|---|---|
| 저승사자 | 명부와 규칙에 집착하는 공무원 | 점잖은 척하다 숨차면 무너지는 아저씨 | 낮고 느린 남자, 감정 없음, 울림 | 경주 "자네", 공포 "너" |
| 도깨비 | 허풍 센 장난꾸러기 | 호탕하고 수다스러운 아재 | 굵고 거친 목소리, 으르렁 | "이놈" |
| 처녀귀신 | 외롭고 집착한다 | 새침하고 잘 삐지는 언니 | 가냘프고 떨리는 여자, 흐느낌, 속삭임 | "거기 너" |
| 강시 | 뻣뻣하고 우직하다 | 딱딱 끊어 말하는 무뚝뚝이 | 숨 없는 단조로운 목소리, 뚝뚝 끊김 | 없음 |
| 구미호 | 능청스럽고 교활하다 | 능청과 애교 | 달콤하게 부르다 섬뜩하게 바뀜 | "얘" |
| 장산범 | 흉내쟁이 | 캐스터 성대모사하는 장난꾸러기 | 여러 목소리를 흉내, 끝이 뒤틀림 | 흉내 대상 따라 |
| 홍콩할매 | 빠르고 수다스러운 할머니 | 잔소리 많은 할머니 | 쉰 웃음, 고양이 소리가 섞임 | "얘야" |
| 빨간마스크 | 외모에 집착한다 | 자기애 넘치는 언니 | 마스크 너머 속삭임 | "너" |

| 괴물 | 몸 소리 | 표식 | 변조 초안 |
|---|---|---|---|
| 저승사자 | 느린 짚신 발걸음, 도포 스침 | 요령(방울) 딸랑, 명부 넘기는 소리 | 피치 -3반음, 긴 동굴 잔향 |
| 도깨비 | 쿵쿵 무거운 맨발 | 방망이로 땅 치기, 호탕한 웃음, "네 이놈!" | 피치 -4반음, 약한 찌그러짐 |
| 처녀귀신 | 소복 스침, 머리카락 끌림 | 흐느낌, 긴 한숨 | 속삭임 겹치기, 역잔향, 약한 떨림 |
| 강시 | 콩 콩 두 발 착지, 관절 뚝뚝 | 부적 종이 펄럭 | 잔향 없음, 짧게 끊기, 약한 비트크러시 |
| 구미호 | 가벼운 발소리, 꼬리 스침 | 여우 울음, 킥킥 웃음 | 약한 코러스, 말끝 피치 올림 |
| 장산범 | 네 발로 뛰는 소리, 흰 털 스침, 덤불 | 앞에서 들리는 흉내 목소리, 낮은 그르렁 | 흉내 목소리에 피치 흔들림, 끝을 뒤틀기 |
| 홍콩할매 | 다다닥 빠른 발걸음 | 할머니 웃음, 고양이 하악 | 포먼트 올림, 거친 목, 고양이 소리 겹치기 |

- 괴물마다: 몸 소리 루프 2~4개, 표식 3~5개, 잡힘 비명 2개
- 공포 조임의 괴물별 신호: 저승사자 방울이 빨라짐, 도깨비 "네 이놈!", 처녀귀신 소리가 사라짐, 강시 콩콩이 빨라짐, 구미호 옆에서 부르는 목소리, 장산범 앞에서 흉내 목소리, 홍콩할매 웃음, 빨간마스크 "나 예뻐?"

## 10. 대사 쓰기 규칙

- 한 마디 1~4초. 뛰면서 듣는다. 길면 둘로 나눈다
- 경주
  - 뒤: 비굴, 애원, 핑계. 앞: 놀림, 으스댐. 추월당함: 억울
  - 웃음은 말장난, 허세, 괴물 설정에서 나온다(방망이, 틀니, 명부, 부적)
- 공포
  - 짧게, 반복, 속삭임. 이름 대신 "너"
  - 멀면 한두 단어, 가까울수록 문장이 짧아진다

- 연기 지시를 칸으로 둔다: 비굴하게, 숨차게, 속삭이듯
- 대사표 칸: 번호, 모드, 괴물, 상황, 변형 번호, 대사, 연기 지시, 목표 길이(초)

## 12. 모델 테스트

- 목적: 모델마다 잘하는 일을 찾아 일을 나눈다
- 후보(Modal에서 돌릴 수 있고 상용 사용이 되는 라이선스)

| 일 | 후보 | 라이선스 | 비고 |
|---|---|---|---|
| TTS | Qwen3-TTS | Apache-2.0 | 지금 qwen_modal.py. 목소리 설계(설명문으로 목소리 만들기) |
| TTS | CosyVoice 3 | Apache-2.0 | 한국어, 감정·속도 지시, 짧은 녹음으로 목소리 복제 |
| TTS | Chatterbox Multilingual | MIT | 한국어, 감정 과장 조절 |
| 목소리 변조 | DSP 프리셋 | 해당 없음 | 피치, 포먼트, 잔향, 속삭임 겹치기 |
| 목소리 변조 | Seed-VC | GPL-3.0(프로그램) | 1~30초 참조로 음색 변환 |
| 효과음 | Stable Audio Open 1.0 | Stability 커뮤니티 라이선스(연 매출 100만 달러 미만 상업 사용 가능) | 목소리는 못 만든다. 허깅페이스 약관 동의 계정 토큰 필요 |
| 효과음 | CC0 녹음 검색 | CC0 | 기존 수집 도구와 분류기 검사 |

- 뺀 것: Fish Audio(상용은 유료 라이선스), 연구용 전용 모델(TangoFlux 등)
- 방법
  - TTS: 11장 30줄을 세 모델로 2테이크씩
  - 음색을 맞춰 연기만 비교한다. Qwen3 목소리 설계로 역할별 참조 목소리를 만들고, 그 소리를 CosyVoice와 Chatterbox의 참조로 넣는다
  - 변조: 같은 대사를 DSP 프리셋과 Seed-VC로 괴물 음색에 입혀 본다
  - 효과음 10종(발소리 3, 방울, 가위, 여우 울음, 추월 휙, 밤 배경, 심장, 닭 울음)을 AI 생성과 CC0 검색 둘 다로
- 검수 페이지: 엔진을 가린 A/B/C 듣기. 역할마다 1등과 메모. 결과로 역할별 담당 모델을 정한다
- 비용: Modal L4 기준 몇 달러 안쪽
- 안 되면: 두 사람이 녹음하고 변조한다(녹음 가이드는 그때 쓴다)
