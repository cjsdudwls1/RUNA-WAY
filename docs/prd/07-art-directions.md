# 아트 · 프론트엔드 방향 초안

- 2026-09-10. 글로 먼저 느낌을 상상하고 고르기 위한 초안 5종
- 각 안은 지도, 적 표현, 색, 글꼴, 첫 화면, 장단점, 1인+AI 제작 난이도로 정리
- 현실성 컨셉과 어트랙션 톤을 동시에 만족해야 함

## A. 야간 관제실

- 한 줄: 국립공원 레인저 관제실의 야간 모니터. 내가 관제 대상이다
- 첫 화면: 검은 배경에 초록 레이더 스윕. 상단에 "레인저 오퍼레이터 온라인". 시작 버튼은 무전기 PTT 모양
- 지도: 어두운 지도 위에 도로만 가는 선. 내 위치는 흰 삼각형, 적은 열원처럼 붉은 얼룩
- 적 표현: 스프린트 시 얼룩이 커지며 깜빡임, 지침 시 흐려짐. 실루엣 없이 열원만. 정체는 도감에서
- 색: 검정, 형광 초록, 경고 주황. 낮에는 반전 없이 그대로(러닝 중 야외 가독성은 검정 바탕 흰 글자가 유리)
- 글꼴: 모노스페이스 숫자 + 고딕. 계기판 느낌
- 소리와의 궁합: 무전 노이즈, 오퍼레이터 콜사인. 어트랙션 톤과 자연스럽게 맞음
- 장점: 에셋 거의 없음. 열원 표현은 코드로 그림. OLED에서 배터리 유리. 현실성 강함
- 단점: 동물 캐릭터 매력이 약함. 공유 카드가 밋밋할 수 있음
- 난이도: 낮음. 캐릭터 일러스트 없이 시작 가능

## B. 내셔널지오그래픽 도감

- 한 줄: 종이 질감 위의 야생 다큐. 동물은 세밀한 실루엣과 데이터 라벨로
- 첫 화면: 크림색 종이, 오늘의 동물 실루엣 한 장, 학명과 실측 수치가 각주처럼
- 지도: 지형도 느낌. 등고선, 갈색 선. 내 위치는 나침반 바늘
- 적 표현: 실루엣 아이콘 + 종이에 찍은 붉은 인장 같은 위협 반경. 스프린트 시 인장이 번짐
- 색: 크림, 먹색, 붉은 인장, 세피아
- 글꼴: 세리프 제목 + 고딕 본문. 라벨은 작은 대문자
- 소리와의 궁합: 다큐 내레이션과 잘 맞음. 어트랙션 톤과는 약간 충돌
- 장점: 현실성 컨셉을 시각으로 가장 잘 설명. 도감·공유 카드가 예쁨
- 단점: 러닝 중 야외 가독성이 밝은 바탕이라 불리. 긴박감 약함
- 난이도: 중간. 실루엣 25종 필요(AI 생성 가능)

## C. 어트랙션 포스터

- 한 줄: 테마파크 사파리 라이드 포스터가 앱이 됐다
- 첫 화면: 굵은 손글씨 로고, 과장된 카툰 동물이 화면 밖으로 튀어나옴. "탑승 시작"
- 지도: 채도 높은 지도. 도로는 노란 리본. 내 위치는 카트 아이콘
- 적 표현: 카툰 동물 얼굴 + 말풍선 효과음("쿵!", "으르렁"). 스프린트 시 스피드 라인
- 색: 정글 초록, 주황, 노랑, 검정 외곽선
- 글꼴: 두꺼운 디스플레이 손글씨 + 둥근 고딕
- 소리와의 궁합: 점프 스케어, 과장 내레이션과 완벽히 맞음
- 장점: 재미와 공유 확산력 최고. 비러너 진입 장벽 낮음
- 단점: 현실성 컨셉과 정면 충돌. 수치를 진지하게 받아들이기 어려움. 캐릭터 25종 제작 부담 최대
- 난이도: 높음. 캐릭터 품질이 전체를 좌우

## D. 스포츠 워치

- 한 줄: 가민·나이키 러닝 화면에 붉은 점 하나가 추가됐다
- 첫 화면: 검정 바탕, 큰 숫자 하나(오늘 거리), 아래에 작은 동물 실루엣과 "치타 · 4.5 km/h"
- 지도: 최소화. 화면 하단 1/3만. 나머지는 페이스·게이지 대형 숫자
- 적 표현: 붉은 점과 방향 화살표만. 실루엣은 시작·결과 화면에서만
- 색: 검정, 흰색, 붉은 점, 초록 게이지
- 글꼴: 숫자 전용 굵은 산세리프, 매우 큼
- 소리와의 궁합: 소리가 주역이 됨. 화면은 보조
- 장점: 러너에게 익숙. 가독성과 배터리 최고. 제작 가장 쉬움
- 단점: "지도 위 적"이라는 훅이 약해짐. 게임 느낌 부족
- 난이도: 가장 낮음

## E. 야간 투시경

- 한 줄: 화면 전체가 야간 투시경. 동물은 어둠 속 눈 두 개
- 첫 화면: 녹색 노이즈, 화면 가장자리 비네트, 중앙에 "장비 착용 완료"
- 지도: 녹색 단색 지도. 도로는 밝은 녹색, 건물은 어두운 녹색
- 적 표현: 배회 시 어둠 속 눈 두 개만. 감지되면 실루엣이 드러남. 스프린트 시 실루엣이 커지며 화면 흔들림
- 색: 녹색 단색 + 붉은 위협만 예외
- 글꼴: 스텐실 또는 각진 고딕
- 소리와의 궁합: 점프 스케어와 최고 궁합. "눈만 보이다가 튀어나옴"
- 장점: 몰입감 최고. 색 하나라 에셋 단순. OLED 배터리 유리
- 단점: 주간 러닝에서 어색. 색각 이상 대응 어려움(녹색 단색). 오래 보면 피로
- 난이도: 중간. 눈·실루엣 25종은 단순 도형으로 가능

## 추천

- 1순위 A 관제실 + B 도감 결합: 러닝 중 화면은 A, 시작·결과·도감 화면은 B
  - 이유: 러닝 중에는 어둡고 단순한 화면이 안전·배터리·가독성에서 이기고, 멈춰서 보는 화면에서는 실측 데이터를 도감처럼 보여주는 게 현실성 컨셉을 살림
  - 오퍼레이터 무전 톤이 A와 맞고, 어트랙션 연출은 소리가 담당
- 2순위 E 투시경: 몰입감이 필요하면. 단 주간 모드를 별도로 만들어야 함
- C 포스터는 시즌 이벤트(핼러윈 좀비 등) 스킨으로 남겨둠

## 프론트엔드 구조 (안 무관 공통)

- 화면 5개: 홈(오늘의 동물 + 시작), 준비(거리·티어 선택, 브리핑), 러닝(지도 + 게이지), 결과(대결 요약 + 공유), 도감
- 러닝 화면은 상태 머신 4상태 x 거리 3구간을 그대로 시각 상태로 사용. 소리 매트릭스와 1:1
- 테마 토큰(색·글꼴·아이콘 슬롯)을 처음부터 분리. A/B 결합이나 시즌 스킨을 토큰 교체로 처리
