## 화면 흐름

- 첫 화면 하나에서 끝낸다. 모드 고르기 화면 없음
  - 맨 위 지난 기록 한 줄(날짜, 종류, 거리, 시간, 결과)
  - 운동 종류: 일반런 / 빌드업 / 인터벌. 고르면 아래에 방식과 추천 대상 설명
  - 값: 일반런(거리, 페이스), 빌드업(거리, 시작 페이스, 종료 페이스), 인터벌(인터벌 페이스, 세트당 거리, 세트 수, 회복 시간)
  - 요약 한 칸: 출발 간격, 페이스, 완주 시간
  - 값은 -/+ 버튼(누르고 있으면 연속) 또는 숫자를 눌러 직접 입력
    - 페이스·회복: 5:30, 5.30, 530 모두 5분 30초. 회복은 숫자만 쓰면 초
    - 거리: km. 100 이상이면 m로 본다. 세트당 거리: m. 20 미만이면 km로 본다
    - 못 읽는 값은 원래 값으로 돌아간다
  - 버튼을 누를 때마다 작은 딸깍
  - 출발 버튼
- 마지막 설정을 기억한다. 다시 켜면 그 값 그대로, 요약 칸에 '지난번 설정' 표시(값을 바꾸면 사라짐). 앱 열고 출발 한 번
- 출발 → 주행 → 결과 → 다시(첫 화면)
- 설정(첫 화면 아래 접기): GPS 확인, 실주행/실내 데모, 아이폰 소리, 소리 검수
- 첫 실주행 출발 때만 안전 고지

## 규칙

- 위치는 1차원. 지도 없음. 내 이동 거리 대 추격자 이동 거리
- 추격자 속도 = 1000 / 목표 페이스(초/km) m/s
- 빌드업: 목표 페이스가 거리에 따라 시작 → 종료로 곧게 변한다. 완주 시간 = 거리 × 두 페이스 평균
- 인터벌: 세트마다 추격자가 새로 출발. 회복 중에는 없음. 회복 6초 전 다음 세트 예고, 3초 전부터 카운트다운
- 출발: 첫 위치 확보 → 준비 4초 → 3, 2, 1 → 출발
- 추격자는 설정 페이스로 15초 갈 거리만큼 뒤에서 출발(최소 25m). 6:00/km면 약 42m
- 거리 0m가 되면 잡힘. 횟수 +1, 추격자는 다시 출발 간격만큼 뒤로. 주행은 계속
- 결과: 0회면 탈출 성공, 아니면 잡힌 횟수. 가장 가까이 온 거리
- 멈춤
  - 5초 넘게 멈추면 자동 일시정지. 추격자도 멈춘다. 신호등에서 무리하지 않게
  - GPS가 끊기거나 정확도가 30m보다 나쁘면 판정 동결. 추격자도 멈춘다
  - 일시정지 버튼도 같다
- 상수는 web/game.js 맨 위 `C`

## 소리

- 말 없음. 발소리, 숨소리, 으르렁, 브금, 효과음만. 목록과 검수표는 18-horror-sounds.md
- 비명과 포효: 잡힐 때(덮칠 때) 반드시. 주행 중에도 50~110초마다 먼 비명이나 먼 포효 하나
- 괴물런 시절 녹음 17개를 그대로 쓴다(web/sounds/README.md). 녹음이 없는 소리는 합성음
- 추격자 발소리는 끊기지 않는다. 오디오 시계로 0.3초 앞까지 미리 예약
- 발 박자 = 설정 페이스의 케이던스(6:00/km 약 165spm)
- 거리 100m 밖은 거의 안 들리고, 가까울수록 크고 밝고 잔향이 줄어든다. 입체 음향으로 바로 뒤에서
