## 화면 흐름

- 첫 화면 하나에서 끝낸다. 모드 고르기 화면 없음
  - 맨 위 지난 기록 한 줄(날짜, 종류, 거리, 시간, 결과)
  - 운동 종류: 일반런 / 빌드업 / 인터벌. 고르면 아래에 방식과 추천 대상 설명
  - 값: 일반런(거리, 페이스), 빌드업(거리, 시작 페이스, 종료 페이스), 인터벌(인터벌 페이스, 세트당 거리, 세트 수, 회복 시간)
  - 요약 한 칸: 출발 간격, 페이스, 완주 시간
  - 값은 -/+ 버튼(누르고 있으면 연속) 또는 숫자를 눌러 직접 입력
    - 페이스·회복: 5:30, 5.30, 530 모두 5분 30초. 회복은 숫자만 쓰면 초
    - 거리: km. 100 이상이면 m로 본다. 세트당 거리: m. 20 미만이면 km로 본다
    - 못 읽는 값은 원래 값으로 돌아간다
  - 버튼을 누를 때마다 작은 딸깍
  - 출발: 밀어서 도망치기 슬라이더. 탭만으로는 출발 안 함(주머니 속 오작동 방지). 키보드는 엔터
- 마지막 설정을 기억한다. 다시 켜면 그 값 그대로, 요약 칸에 '지난번 설정' 표시(값을 바꾸면 사라짐). 앱 열고 출발 한 번
- 출발 → 주행 → 결과 → 다시(첫 화면)
- 설정(첫 화면 아래 접기): GPS 확인, 실주행/실내 데모, 아이폰 소리, 소리 검수
- 첫 실주행 출발 때만 안전 고지

## 규칙

- 위치는 1차원. 지도 없음. 내 이동 거리 대 추격자 이동 거리
- 추격자 속도 = 1000 / 목표 페이스(초/km) m/s. 단, 아래 돌진으로 출렁인다(평균은 그대로)
- 돌진(2026-10-21): 사람은 늘 같은 속도로 오지 않는다. 세트 안에서 움직인 60초마다
  - 0~30초 처짐(0.8배), 30~45초 돌진(1.6배, 상한 초속 6.5m), 45~60초 처짐(0.8배)
  - 60초 평균은 정확히 설정 페이스(45 × 0.8 + 15 × 1.6 = 60)
  - 설정 페이스대로 뛰면 거리가 약 33~58m 사이로 출렁인다. 잡히지는 않는다
  - 조금 느리면 돌진 때 잡힌다. 돌진이 시작되면 웃음
  - 세트가 30초보다 짧으면 돌진 없이 처짐만(조금 쉬워진다)
- 빌드업: 목표 페이스가 거리에 따라 시작 → 종료로 곧게 변한다. 완주 시간 = 거리 × 두 페이스 평균
- 인터벌: 세트마다 추격자가 새로 출발. 회복 중에는 없음. 회복 6초 전 다음 세트 예고, 3초 전부터 카운트다운
- 출발: 첫 위치 확보 → 준비 4초 → 3, 2, 1 → 출발
- 추격자는 설정 페이스로 15초 갈 거리만큼 뒤에서 출발(최소 25m). 6:00/km면 약 42m
- 거리 0m가 되면 잡힘. 횟수 +1, 추격자는 다시 출발 간격만큼 뒤로. 주행은 계속
- 결과: 0회면 탈출 성공, 아니면 잡힌 횟수. 가장 가까이 온 거리
- 멈춤
  - 5초 넘게 멈추면 자동 일시정지. 추격자도 멈춘다. 신호등에서 무리하지 않게
  - GPS가 끊기거나 정확도가 30m보다 나쁘면 판정 동결. 추격자도 멈춘다
  - 일시정지 버튼도 같다
- 상수는 web/game.js 맨 위 `C`

## 소리

- 목표: 화면을 안 봐도 추격자가 누구고 어디쯤인지 귀로 아는 것
- 2026-10-21: 추격자 = 사람. 동물·괴물 소리(으르렁, 포효, 짐승 숨, 도깨비) 전부 삭제
- 2026-10-28: 한 사람. 소리가 따로 놀아 집중이 안 되고 뛸 때 방해된다는 피드백
  - 주행 한 번 = 소리마다 후보 하나. 발소리는 한 신발 한 바닥, 숨·웃음·'잡았다~'도 한 사람. 높이도 주행 내내 같게
    - 예전에는 발마다 후보를 새로 골라 발소리 일곱 벌(자갈, 흙, 콘크리트…)이 섞였다. 숨 4명, 웃음 5명, 심장 5개도 마찬가지
  - 깔리는 소리는 그의 발소리와 숨뿐. 나머지는 상황이 바뀔 때만
  - 발소리: 운동화가 아스팔트를 딛는 마른 소리. 박자는 고르게(±1%), 한쪽 발이 조금 무겁다. 돌진 때 세지고 박자는 천천히 빨라진다
  - 숨: 40m 안. 발을 딛는 순간에 시작해 발 박자에 묶인다(합성은 한 걸음 들숨, 두 걸음 날숨). 멀면 거리 곡선이 작게. 돌진 때 거칠다
  - 휘파람: 추격이 시작될 때 한 번. 출발 3초 전, 잡힌 뒤 다시 뒤로 갈 때
  - 웃음: 돌진으로 25m 안까지 따라붙었을 때. 90초에 한 번까지
  - 내 심장: 30m 안에서만. 가까울수록 크고 빠르다
  - 잡힐 때: 붙잡힘(옷 낚아채는 소리 + 둔탁한 충돌) + 0.6초 뒤 '잡았다~'. 비명과 쾅은 뺐다(다른 사람 목소리라 따로 논다)
  - 5분 기준(시뮬레이션): 설정 페이스면 휘파람 1번, 웃음 0번, 심장 0초. 조금 느리면 웃음 2번, 심장 157초. 예전은 페이스와 상관없이 휘파람·웃음 15~19번, 심장 301초
- 뺀 소리: 드론, 바람, 불협 현, 카운트다운, 출발 종, 접근 경고, 잡힘 비명, 먼 비명·포효, 삐걱임, 울부짖음, 방울, 발 끄는 소리, 속삭임, 회복, 탈출. 카운트다운과 출발은 진동으로
- 거리감(2026-10-21 다시 맞춤). 추격자 소리는 전부 추격자 자리에서 실제 거리(m)대로
  - 크기: (4 / (d + 4))^1.3. 0m 1.0, 10m 0.20, 30m 0.07, 60m 0.03. 10m와 40m가 12dB 넘게 차이
  - 공기 흡수: 저역 통과 16000 / (1 + d/5). 0m 16kHz, 10m 5.3kHz, 30m 2.3kHz, 60m 1.2kHz. 멀면 먹먹한 쿵, 가까우면 사각거림까지
  - 공간: 긴 잔향 삭제. 골목 벽 반사 4개 + 0.08초 꼬리(전체 0.45초). 반사음은 직접음에 비례(멀수록 비율만 0.06 → 0.36)
  - 근접: 5m 안에서 저음 최대 +9dB(근접 효과). 15m 안에서 좌우 발이 벌어진다(최대 약 40도)
  - 방향: 입체 음향(HRTF)으로 뒤. 앞뒤 혼동을 막으려 좌우로 조금씩 흔들린다
  - 리미터는 클리핑만 막는다(-4dB, 4:1). 예전(-8dB, 12:1)은 가까운 소리를 눌러 거리감을 지웠다
- 고친 이유(2026-10-21 피드백): 예전 엔진은 발소리가 100m에서 0m로 올수록 오히려 작아졌고(-32 → -46dB), 잔향 꼬리가 발소리만큼 컸다. 지금은 -52 → -7dB, 꼬리 -55dB 아래
- 녹음 후보 고르기(소리 검수)도 위 소리만

## 점진적 과부하

- 목표: 같은 설정에서 잡히는 횟수를 줄이고, 0회가 되면 페이스나 거리를 올리게 한다
- 같은 설정 = 운동 종류 + 값 전부가 같음. 값을 하나라도 바꾸면 새 기록으로 센다
- 비교에서 빼는 기록: 실내 데모, 중단
- 첫 화면과 결과 화면에 같은 설정의 잡힌 횟수 막대(최근 8회)
- 결과 화면: 지난번 대비 줄었는지, 같은지, 늘었는지 한 줄
- 마지막 기록이 0회면 다음 단계 두 가지를 제안. 누르면 그 값으로 바뀌고 첫 화면으로
  - 일반런: 페이스 10초/km 빠르게, 또는 거리 10% 늘리기(100m 단위)
  - 빌드업: 시작·종료 페이스 둘 다 10초/km 빠르게, 또는 거리 10%
  - 인터벌: 인터벌 페이스 5초/km 빠르게, 또는 세트 1개 추가
- 기록은 이 기기에만(localStorage `rw.runs`, 최근 200개)
