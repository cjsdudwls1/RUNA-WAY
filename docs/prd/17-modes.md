# 17. 개편: 경주 모드 / 공포 모드

- 날짜: 2026-10-05
- 요청: 앱 단순화. 동물 추격자와 동물별 목소리·대사 전부 삭제
- 결과: 상대 하나. 사용자가 정한 페이스 그대로 달리는 가상 주자

## 화면 흐름

- 첫 화면: 모드 고르기
  - 경주 모드: 당신을 긁는 짜증나는 상대와 경주해 보세요. 상대는 당신이 설정한 페이스로 뜁니다
  - 공포 모드: 당신을 쫓아오는 아무개씨를 피해 도망가세요. 상대는 당신이 설정한 페이스로 당신을 쫓아옵니다
- 두 번째 화면: 운동 종류와 값
  - 일반런: 거리, 페이스
  - 빌드업: 거리, 시작 페이스, 종료 페이스
  - 인터벌: 인터벌 페이스, 세트당 거리, 세트 수, 회복 시간
- 출발 → 주행 → 결과
- 설정(첫 화면 아래 접기): GPS 확인, 실주행/실내 데모, 아이폰 소리, 소리·대사 검수

## 규칙

- 상대 위치는 1차원. 지도 없음. 내 이동 거리 대 상대 이동 거리
- 상대 속도 = 1000 / 목표 페이스(초/km) m/s
- 빌드업: 목표 페이스가 거리에 따라 시작 → 종료로 곧게 변한다. 상대 완주 시간 = 거리 × 두 페이스 평균
- 인터벌: 세트마다 상대가 새로 출발. 회복 중에는 상대 없음. 회복 6초 전 다음 세트 예고, 3초 전부터 카운트다운
- 출발: 첫 위치 확보 → 준비 4초 → 3, 2, 1 → 출발
- 경주
  - 상대는 옆에서 같이 출발
  - 승패는 결승 시간 비교. 상대가 먼저 도착하면 결승선에서 멈춰 기다린다
  - 인터벌은 세트별 승패, 최종은 이긴 세트 수
- 공포
  - 아무개씨는 설정 페이스로 15초 갈 거리만큼 뒤에서 출발(최소 25m). 6:00/km면 약 42m
  - 거리 0m가 되면 잡힘. 횟수 +1, 아무개씨는 다시 출발 간격만큼 뒤로. 주행은 계속
  - 결과: 0회면 탈출 성공, 아니면 잡힌 횟수
- 멈춤
  - 5초 넘게 멈추면 자동 일시정지. 상대도 멈춘다. 신호등에서 무리하지 않게
  - GPS가 끊기거나 정확도가 30m보다 나쁘면 판정 동결. 상대도 멈춘다
  - 일시정지 버튼도 같다
- 상수는 web/game.js 맨 위 `C`, 해설 기준은 `Z`

## 소리

- 공포 모드: 말 없음. 발소리, 브금, 효과음만. 목록과 검수표는 18-horror-sounds.md
  - 아무개씨 발소리는 끊기지 않는다. 오디오 시계로 0.3초 앞까지 미리 예약
  - 발 박자 = 설정 페이스의 케이던스(6:00/km 약 165spm)
  - 거리 100m 밖은 거의 안 들리고, 가까울수록 크고 밝고 잔향이 줄어든다. 입체 음향으로 바로 뒤에서
- 경주 모드: 상대 대사 + 짧은 효과음(카운트다운, 호루라기, 추월, 승리, 패배)
  - 대사표: web/race_lines.md. 사용자가 직접 쓴다. 상황 37개
  - 읽기: 기기 내장 음성(TTS). 신경망 음성 팩은 대사가 확정되면 다시 굽는다
- 모든 소리는 절차 합성. 같은 id의 녹음을 web/sounds/에 넣으면 그 소리만 바뀐다
