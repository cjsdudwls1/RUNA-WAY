# 18. 공포 모드 소리 검수표

- 날짜: 2026-10-21 사람 추격자로 다시 씀 (이전: 2026-10-05, 10-08, 10-09)
- 추격자는 사람 하나. 휘파람 부는 남자. 아래 소리가 주행 소리 전부다
- 말은 잡힐 때 "잡았다~" 하나뿐
- 코드는 web/sound.js, 녹음 출처는 web/sounds/credits.json
- 이어폰으로 들을 것. 추격자 소리는 입체 음향으로 뒤에서 난다. 스피커로 들으면 거리감과 방향이 사라진다

## 듣는 법

- 앱: 첫 화면 > 설정 > 소리 검수. 소리를 펼쳐 후보마다 ▶로 듣고 '사용'을 켜고 끈다
- 주행은 고른 후보만, 여럿이면 무작위. '이것만', '전부', '끄기'
- 01 전체 장면부터. 100m 뒤에서 발소리 → 휘파람 → 다가옴 → 웃음 → 숨 → 붙잡힘
- WAV: `NODE_PATH=$(npm root -g) node web/render_sounds.mjs` → web/dist/sounds/. 합성음만 굽는다

## 검수 방법

- 판정: 통과 / 수정 / 교체
  - 수정: 메모에 원하는 방향(더 낮게, 더 길게, 덜 기계적으로 등)
  - 교체: 다른 녹음으로. `web/sounds/<id>/<후보>.mp3`로 넣으면 끝. 규격은 web/sounds/README.md
- 같이 볼 것
  - 30m와 10m가 귀로 구분되는가
  - 발소리가 울리지 않고 또렷한가
  - 소리 전부가 한 사람으로 들리는가

## 거리에 따른 변화 (실주행, web/sound.js `GAP`)

- 크기 (4 / (d + 4))^1.3. 0m 1.0, 10m 0.20, 30m 0.07, 60m 0.03
- 밝기(저역 통과) 16000 / (1 + d/5) Hz. 0m 16k, 10m 5.3k, 30m 2.3k, 60m 1.2k
- 반사음 0.06 + 0.3 × (d/60). 직접음 뒤에서 나눠 같이 작아진다
- 근접 저음 5m 안에서 최대 +9dB, 좌우 발 벌어짐 15m 안에서 최대 약 40도
- 심장 60m 안에서 70 → 160bpm
- 미리듣기는 near(0 멀다 ~ 1 붙음) 곡선 `LV`로 같은 흐름
