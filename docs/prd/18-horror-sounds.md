# 18. 공포 모드 소리 검수표

- 날짜: 2026-10-05, 2026-10-08 녹음 반영
- 공포 모드는 말이 없다. 아래 소리가 전부다
- 잡힐 때는 포효(pounce) + 비명(caught)이 반드시 난다
- 주행 중에도 50~110초마다 먼 비명(scream)이나 먼 포효(roar) 중 하나가 난다
- 녹음 칸이 있는 소리는 괴물런 시절 녹음(web/sounds/README.md). 나머지는 합성음. 코드는 web/sound.js
- 이어폰으로 들을 것. 발소리는 입체 음향으로 바로 뒤에서 난다. 스피커로 들으면 거리감과 방향이 사라진다

## 듣는 법

- 앱: 첫 화면 > 설정 > 소리 · 대사 검수. 항목마다 재생 버튼. 주행 중과 같은 코드
- WAV: `NODE_PATH=$(npm root -g) node web/render_sounds.mjs` → web/dist/sounds/. 합성음만 굽는다(녹음은 web/sounds/에서 바로 듣는다)
- 01 전체 장면부터. 실제 주행 순서대로 섞어 놓았다(종 → 100m 밖 발소리 → 울부짖음 → 으르렁 → 속삭임 → 접근 경고 → 덮침)

## 검수 방법

- 판정 칸: 통과 / 수정 / 교체
  - 수정: 메모에 원하는 방향(더 낮게, 더 길게, 덜 기계적으로 등). 합성 값을 고친다
  - 교체: 다른 녹음으로 바꾼다. `web/sounds/<id>_1.mp3` 이름으로 넣으면 끝. 규격은 web/sounds/README.md
- 전체 균형(브금이 발소리를 덮는지, 비명이 너무 큰지)도 메모로

## 거리에 따른 변화

- near = 1 - 거리/100m. 100m 밖 0, 붙으면 1
- 발소리 크기 0.03 + 0.97 × near², 밝기 450 + 7500 × near² Hz, 잔향은 멀수록 많이
- 드론 0.12 + 0.3 × near, 불협 현은 45m 안에서 0 → 0.25
- 심장 70 → 160bpm
- 이 곡선은 web/sound.js의 `LV`
