# 18. 공포 모드 소리 검수표

- 날짜: 2026-10-05
- 공포 모드는 말이 없다. 아래 소리가 전부다
- 전부 절차 합성(파일 없음). 코드는 web/sound.js
- 이어폰으로 들을 것. 발소리는 입체 음향으로 바로 뒤에서 난다. 스피커로 들으면 거리감과 방향이 사라진다

## 듣는 법

- 앱: 첫 화면 > 설정 > 소리 · 대사 검수. 항목마다 재생 버튼. 주행 중과 같은 코드
- WAV: `NODE_PATH=$(npm root -g) node web/render_sounds.mjs` → web/dist/sounds/. 파일 이름이 아래 번호와 같다
- 01 전체 장면부터. 실제 주행 순서대로 섞어 놓았다(종 → 100m 밖 발소리 → 접근 → 속삭임 → 접근 경고 → 잡힘)

## 검수 방법

- 판정 칸: 통과 / 수정 / 교체
  - 수정: 메모에 원하는 방향(더 낮게, 더 길게, 덜 기계적으로 등). 합성 값을 고친다
  - 교체: 녹음으로 바꾼다. `web/sounds/<id>_1.mp3` 이름으로 넣으면 끝. 규격은 web/sounds/README.md
- 전체 균형(브금이 발소리를 덮는지, 비명이 너무 큰지)도 메모로

## 거리에 따른 변화

- near = 1 - 거리/100m. 100m 밖 0, 붙으면 1
- 발소리 크기 0.03 + 0.97 × near², 밝기 450 + 7500 × near² Hz, 잔향은 멀수록 많이
- 드론 0.12 + 0.3 × near, 불협 현은 45m 안에서 0 → 0.25
- 심장 70 → 160bpm
- 이 곡선은 web/sound.js의 `LV`

|---|---|---|---|---|---|---|

| 02 | drone | 저음 드론 | 공포모드 내내 깔린다. 가까워질수록 커진다 | 41Hz 톱니파 둘을 살짝 어긋나게 겹친 맥놀이 + 서브 + 저역 럼블. 필터가 느리게 숨 쉰다 | | |
| 03 | wind | 바람 | 공포모드 내내. 정적을 메운다 | 브라운 노이즈 + 저역 통과. 돌풍처럼 천천히 일렁인다 | | |
| 04 | tension | 불협 현 | 아무개씨가 약 45m 안으로 들어오면 서서히 커진다 | 반음씩 붙은 고음 현 네 줄의 떨림 + 저음 단2도. 공포 영화 바이올린 | | |
| 05 | step | 아무개씨 발소리 | 달리는 내내 끊기지 않는다. 박자는 설정 페이스의 케이던스, 크기와 밝기는 거리 | 뒤꿈치 쿵 + 흙 밟는 사각. 좌우 발이 번갈아 뒤에서 들린다. 미리듣기는 100m에서 0m까지 | | |
| 06 | heart | 내 심장 | 달리는 내내. 가까워질수록 빨라진다(70~160bpm) | 쿵쿵 두 박. 미리듣기는 느림에서 빠름까지 | | |
| 07 | breath | 아무개씨 숨소리 | 12m 안. 발 두 번에 한 번 | 거친 들숨 날숨. 목이 긁히는 소리가 섞인다 | | |
| 08 | tick | 카운트다운 | 출발 3, 2, 1초 전. 인터벌은 회복 끝 3초 전 | 낮은 시계 초침 | | |
| 09 | bell | 출발 종 | 출발 순간. 아무개씨가 움직이기 시작한다 | 낮은 G 교회 종. 비배음 배음이 길게 운다 | | |
| 10 | close | 접근 경고 | 20m 안으로 들어오는 순간(35m 밖으로 나가야 다시 울림) | 거꾸로 빨려드는 스웰 뒤 쾅. 진동 함께 | | |
| 11 | caught | 잡힘 | 거리 0m. 잡힌 횟수 +1, 아무개씨는 다시 뒤로 | 찢어지는 비명 + 쾅. 화면 번쩍, 긴 진동 | | |
| 12 | creak | 먼 삐걱임 | 25m 밖일 때. 35~80초마다 한 번, 왼쪽이나 오른쪽 멀리서 | 녹슨 철문이 멀리서 끼익. 좌우 한쪽에서 울린다 | | |
| 13 | whisper | 속삭임 | 25m 안일 때. 삐걱임 대신 35~80초마다 한 번, 귀 옆에서 | 숨 섞인 하아아. 말은 없다 | | |
| 14 | safe | 잠시 안전 | 인터벌 세트 끝, 회복 시작. 발소리가 멎는다 | 낮은 단조 화음이 천천히 떴다 가라앉는다 | | |
| 15 | door | 탈출 | 목표 거리 완주 | 문이 끼익 열리고 쾅 닫힌 뒤 걸쇠가 걸린다 | | |
