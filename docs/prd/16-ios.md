# 아이폰 대응

- 2026-09-24. 사용자 질문 "아이폰에서도 가능?"에서 시작
- 배포 방식은 그대로: 사파리로 링크 열기, 또는 공유 → 홈 화면에 추가
- 앱스토어는 보류. 웹을 감싼 앱은 애플 심사에서 거절되는 경우가 많다

## 고친 것

| 문제 | 원인 | 조치 |
|---|---|---|
| 무음 모드면 소리가 전부 안 남 | 아이폰 무음 스위치가 웹 오디오를 끈다 | 오디오 세션을 재생용(playback)으로 선언. iOS 16.4 이전은 소리 없는 audio 요소를 돌리는 우회 |
| 제자리에서 돌아도 지도가 안 돎 | 아이폰은 방향 센서에 권한이 필요. 아이폰의 alpha는 나침반 기준이 아님 | 출발 버튼에서 권한 요청. iOS가 주는 webkitCompassHeading(북 기준 시계 방향)을 읽음 |
| 지도가 하얗게 나옴 | 사파리는 캔버스 filter 미지원. 다크 지도 처리가 통째로 빠짐 | 타일을 받을 때 픽셀을 직접 변환. 크롬 filter 결과와 최대 차이 2/255 |
| 전화 뒤 소리가 안 돌아옴 | iOS는 끼어든 소리가 끝나도 오디오를 다시 켜지 않을 때가 있음 | 화면을 만지거나 앱으로 돌아오면, 그리고 주행 중 5초마다 다시 켬 |
| 화면이 꺼지면 기록이 멈춤 | 화면 꺼짐 방지는 iOS 16.4부터. 홈 화면 앱은 18.4 전까지 결함 | 실패하면 10초간 안내: 설정 > 디스플레이 및 밝기 > 자동 잠금 > 안 함 |
| 길게 누르면 글자 선택, 메뉴 | 사파리 기본 동작 | 막음. 입력칸만 예외 |

## 사용자가 고르는 것: 아이폰 소리

- 재생용 오디오는 무음 모드를 뚫는 대신 다른 앱 음악을 멈춘다. 웹에서는 둘 다 얻는 방법이 없다
- 설정 > 아이폰 소리 (아이폰에서만 보인다)

| 선택 | 무음 모드 | 듣던 음악 |
|---|---|---|
| 무음에서도 들림 (기본) | 들림 | 멈춤 |
| 음악과 같이 | 안 들림 | 같이 들림 |

- 기본을 "무음에서도 들림"으로 둔 이유: 소리가 이 게임의 전부다. 무음 모드인 줄 모르고 켜면 고장 난 앱으로 읽힌다

## 못 고치는 것

- 진동: 아이폰 사파리는 진동 API가 없다. 돌진·피격은 소리로만 알린다
- 화면 끄고 주머니: 웹앱은 화면이 꺼지면 멈춘다. 안드로이드와 같다. 화면을 켠 채 검게 가리는 "주머니" 버튼을 쓴다

## 검증

- 실기 검증 0회. 이 환경에는 사파리 엔진이 없다
- 헤드리스 크롬에서 아이폰을 흉내 내서 확인 (web/qa.mjs 6, 6b)
  - 아이폰 UA, 사파리에만 있는 것(오디오 세션, 나침반 권한, webkitCompassHeading)을 넣고 사파리에 없는 것(캔버스 filter)을 뺐다
  - 소리 설정 전환 → 오디오 세션 ambient/playback 전환
  - 출발 버튼에서 나침반 권한 요청 1회. 실내 데모에서는 묻지 않음
  - 나침반 90°를 흘려보내면 지도가 돌아 북쪽 표시가 왼쪽으로
  - 흰 타일이 어둡게 그려짐 (평균 밝기 5/255). 변환을 막은 대조군은 하얗게 나옴
  - 옛 iOS(오디오 세션 없음)에서 무음 audio 우회 재생

## 실기에서 볼 것

- 무음 스위치 켠 상태로 소리 테스트 버튼
- 출발 때 "동작 및 방향 접근" 권한 창이 뜨는지, 허용 후 제자리에서 돌면 지도가 도는지
- 지도가 어두운지
- 음악 앱을 켜 둔 채 "음악과 같이"로 바꿨을 때 둘 다 들리는지
