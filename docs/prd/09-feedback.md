# 사용자 피드백 로그

## 2026-09-11 · 음성 메모 (프로토타입 v0.1 첫 사용)

원문 요지 (로컬 STT로 전사, 일부 오인식 보정)

| # | 피드백 | 조치 (v0.2) |
|---|---|---|
| 1 | 워밍업 시간이 보이면 긴장감이 덜하다 | 타이머 숨김. 대신 "1분 뒤 녀석이 널 본다", "곧이다" 음성으로만 |
| 2 | 레이더 말고 실제 위치 지도가 보였으면 | 지도 타일(CARTO 다크) 추가. 아티팩트 뷰어는 외부 이미지 차단이라 GitHub Pages 주소에서만 표시. 차단 시 레이더로 자동 전환 |
| 3 | 실제 지형지물을 반영한 추격이면 더 재밌을 듯 | 도로망 추종은 라우팅 그래프 필요. 지도 타일로 시각 반영 먼저, 경로 추종은 2차 |
| 4 | 배경음(바람)은 좋다, 실감 난다. 어떻게 만든 건지 | 브라운 노이즈(랜덤 워크) → 400Hz 로우패스 → 낮은 게인 루프. 코드 audioInit() |
| 5 | 3분 넘게 적이 안 나타나니 루즈하다 | 워밍업 2분으로. 워밍업 중에도 20초마다 멀리서 소리, 심박 유지 |
| 6 | GPS 모드에서 내 속도가 안 변하고 적도 안 나타났다 | 홈에 GPS 확인 버튼(권한·정확도 표시), 러닝 화면에 권한 거부·신호 없음 배너. 원인 후보: 권한 미허용 또는 아티팩트 뷰어 iframe 제한 → Pages 주소로 재확인 필요 |
| 7 | 적이 하얀 점이라 재미없다. 닭이면 닭소리, 멀어질 때 소리가 기계음 | 동물 이모지로 표시. 동물군(조류·개과·고양이과·파충류·발굽·소형)별 소리 재합성. 거리 표현을 피치 변조 대신 게인 + 로우패스로. 실제 샘플은 sounds/에 넣으면 빌드에 자동 포함 |
| 8 | 결과 화면 가독성 나쁨. 다른 앱 참고 후 결정 | 임시로 큰 시간 + 3지표 + 한 줄 대결 요약, 상세는 접기. 참고 조사는 별도 |

미해결

- 실제 동물 소리 파일: 이 환경에서 소재 사이트 전부 차단. 사용자가 파일을 주거나 네트워크 열린 환경에서 수집
- 지도 타일은 GitHub Pages 활성화 필요 (Settings → Pages → main / docs)

## 2026-09-11 · 스크린샷 2장 (프로토타입 v0.3)

| # | 피드백 | 조치 (v0.4) |
|---|---|---|
| 1 | 적 출현 빈도를 높여라 | 적을 무리(1·2·3·5마리, 기본 3)로. 배회 중 감지 반경 2배 밖으로 나가면 30초 뒤 뒤·옆에서 재출현. 회복 끝나면 즉시 재교전. 동시 스프린트는 1마리. 피격 시 무리 전체가 200m 뒤로 물러나 지침 (연쇄 피격 방지) |
| 2 | GPS 불가 (권한 정책으로 차단 메시지) | 원인 확정: claude.ai 아티팩트 뷰어가 iframe permissions policy로 geolocation을 막음. 코드 문제 아님. GitHub Pages 주소에서만 GPS 동작. 아티팩트에서는 리플레이 모드로만 확인 |
| 3 | 실제 지도 위에 나와 여러 동물이 보이게 | 적을 2D 좌표로 전환(기존 1D 경로 추종 폐기). 지도 타일 위에 이모지로 무리 전체 표시, 거리 라벨. 타일 역시 아티팩트에서 차단이라 Pages 주소 필요 |

미해결

- GitHub Pages 활성화 (Settings → Pages → Branch: gh-pages 또는 main /docs). 비공개 저장소면 공개 전환 필요
- 도로망 추종 (2D 라우팅)은 2차

헤드리스 리플레이 검증 (10 km/h, 1 km, 무리 3, 워밍업 없음)

| 동물 | 스프린트 | 피격 | 결과 |
|---|---|---|---|
| 닭 | 7 | 0 | 성공. 1D 시뮬(0)과 일치 |
| 진돗개 | 1 | 1 | 성공. 1D 5 km 기준 4회와 비슷한 밀도 |
| 그레이하운드 | 1 | 1 | 성공 |
| 치타 | 2 | 2 | 1 km라 성공. 3 km 이상이면 실패. 설계상 못 깸 |

폐기한 안

- 앞쪽 매복 재출현: 직진 러너는 무조건 30m 안으로 들어가 피격. 닭도 3회 피격시킴. 뒤·옆 재출현으로 교체
- 피격 시 가장 가까운 1마리만 후퇴: 나머지가 12초 안에 연쇄 피격. 무리 전체 후퇴로 교체
- 지침·회복 중 재출현: 피로를 우회해 그레이하운드가 1 km에 2회 피격. 배회 상태에서만 재출현

피드백 (기획)

- 무리 수는 난이도 배수. 홈의 "난이도 N"은 1마리 기준 수치. 무리 3이면 스프린트 빈도 약 3배, 피격도 늘어남. 랭킹을 붙일 때는 무리 수를 고정하거나 기록에 병기해야 함
- 빈도보다 리듬이 긴장을 만듦. 스프린트 → 지침(기회) → 재출현의 60~90초 파도가 현재 구조. 계속 붙어 있으면 소음이 됨
