# 사용자 피드백 로그

## 2026-09-11 · 음성 메모 (프로토타입 v0.1 첫 사용)

원문 요지 (로컬 STT로 전사, 일부 오인식 보정)

| # | 피드백 | 조치 (v0.2) |
|---|---|---|
| 1 | 워밍업 시간이 보이면 긴장감이 덜하다 | 타이머 숨김. 대신 "1분 뒤 녀석이 널 본다", "곧이다" 음성으로만 |
| 2 | 레이더 말고 실제 위치 지도가 보였으면 | 지도 타일(CARTO 다크) 추가. 아티팩트 뷰어는 외부 이미지 차단이라 GitHub Pages 주소에서만 표시. 차단 시 레이더로 자동 전환 |
| 3 | 실제 지형지물을 반영한 추격이면 더 재밌을 듯 | 도로망 추종은 라우팅 그래프 필요. 지도 타일로 시각 반영 먼저, 경로 추종은 2차 |
| 4 | 배경음(바람)은 좋다, 실감 난다. 어떻게 만든 건지 | 브라운 노이즈(랜덤 워크) → 400Hz 로우패스 → 낮은 게인 루프. 코드 audioInit() |
| 5 | 3분 넘게 적이 안 나타나니 루즈하다 | 워밍업 2분으로. 워밍업 중에도 20초마다 멀리서 소리, 심박 유지 |
| 6 | GPS 모드에서 내 속도가 안 변하고 적도 안 나타났다 | 홈에 GPS 확인 버튼(권한·정확도 표시), 러닝 화면에 권한 거부·신호 없음 배너. 원인 후보: 권한 미허용 또는 아티팩트 뷰어 iframe 제한 → Pages 주소로 재확인 필요 |
| 7 | 적이 하얀 점이라 재미없다. 닭이면 닭소리, 멀어질 때 소리가 기계음 | 동물 이모지로 표시. 동물군(조류·개과·고양이과·파충류·발굽·소형)별 소리 재합성. 거리 표현을 피치 변조 대신 게인 + 로우패스로. 실제 샘플은 sounds/에 넣으면 빌드에 자동 포함 |
| 8 | 결과 화면 가독성 나쁨. 다른 앱 참고 후 결정 | 임시로 큰 시간 + 3지표 + 한 줄 대결 요약, 상세는 접기. 참고 조사는 별도 |

미해결

- 실제 동물 소리 파일: 이 환경에서 소재 사이트 전부 차단. 사용자가 파일을 주거나 네트워크 열린 환경에서 수집
- 지도 타일은 GitHub Pages 활성화 필요 (Settings → Pages → main / docs)
