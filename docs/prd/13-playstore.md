# 구글 플레이 출시

## 결론

오늘은 못 올린다. 이유가 두 개고 성격이 다르다.

1. 정책: 개인 개발자 계정은 비공개 테스트를 통과해야 프로덕션 신청이 가능하다
2. 품질: 밖에서 끝까지 도는 주행이 아직 0회다

둘 다 "기다리는 것" 말고는 방법이 없다. 대신 오늘 시작하면 시계가 오늘부터 돈다.

## 정책 장벽

2023년 11월 13일 이후 만든 개인 개발자 계정은

- 비공개 테스트에 **테스터 12명**이 **연속 14일** 옵트인 상태여야 한다
- 그 뒤에야 프로덕션 접근을 신청할 수 있다
- 중간에 빠졌다 들어온 사람은 14일이 처음부터 다시 센다
- 사업자로 등록한 조직 계정은 이 요구가 면제된다

즉 최단 경로도 오늘부터 14일이다. 등록비는 25달러 1회.

| 항목 | 상태 | 판정 |
|---|---|---|
| 좌표 폭주 | 고침, 헤드리스 검증 | 통과 |

| 반응 지연, 방향 고착 | 고침, **실주행 미검증** | 보류 |
| 지도 타일 | OSM 동작 확인 | 통과 |
| 배터리, 발열 | **측정 0회** | 미확인 |
| 화면 끈 상태 오디오 | **실기 검증 0회** | 미확인 |
| 동물 소리 | 합성음. 실제 음원 없음 | 약점 |
| 진행도 저장 | 없음. 해금이 구현 안 됨 | 약점 |
| 개인정보처리방침 | 작성, 배포 완료 | 통과 |
| 안전 고지 | 첫 실행 1회 확인 추가 | 통과 |

**차단 요인은 하나다. 30분짜리 실주행 한 번.** 그 한 번에서 배터리, 발열, 화면 끔, 거리 정확도가 같이 나온다.
그게 없으면 12명에게 깨진 걸 돌리는 셈이고, 테스터 12명은 두 번 모으기 어렵다.

## 오늘 할 일

| 순서 | 할 일 | 걸리는 시간 |
|---|---|---|
| 1 | 30분 실주행. 아래 6개 확인 | 30분 |
| 2 | Play Console 개발자 등록 (25달러) | 20분, 승인 대기 최대 48시간 |
| 3 | PWABuilder로 AAB 만들기 | 10분 |
| 4 | 비공개 테스트 트랙에 업로드, 테스터 12명 초대 | 30분 |
| 5 | 14일 대기하며 피드백으로 고치기 | 14일 |
| 6 | 프로덕션 신청 | |

2번과 3번은 1번 결과를 안 기다려도 된다. 병행한다.

실주행에서 확인할 것

- 거리가 실제와 10% 안인가
- 달릴 때 지도가 진행 방향으로 도는가
- 서 있을 때 안 도는가
- 화면을 끄고 주머니에 넣어도 소리가 계속 나는가
- 30분에 배터리가 몇 퍼센트 빠지는가
- 발열로 손이 뜨거운가

## AAB 만들기

이 환경에는 안드로이드 SDK가 없다(구글 배포 서버가 차단). 직접 빌드해야 한다.
가장 빠른 길은 PWABuilder다. 로컬에 SDK를 깔 필요가 없다.

1. https://www.pwabuilder.com 접속
2. 주소에 `https://cjsdudwls1.github.io/RUNA-WAY/` 입력
3. Package For Stores → Android → Generate
4. 받은 zip 안에 `.aab`(플레이 제출용), `.apk`(직접 설치 테스트용), 서명 키가 들어 있다
5. **서명 키 파일과 비밀번호를 반드시 따로 보관한다.** 잃어버리면 앱 업데이트를 영원히 못 한다

로컬 빌드를 원하면 Bubblewrap을 쓴다.

```
npm i -g @bubblewrap/cli
bubblewrap init --manifest https://cjsdudwls1.github.io/RUNA-WAY/manifest.webmanifest
bubblewrap build
```

### 주소창 숨기기 (선택)

TWA는 도메인 소유를 증명해야 주소창이 사라진다. 증명 파일은 **도메인 루트**에 있어야 한다.
지금 앱은 `cjsdudwls1.github.io/RUNA-WAY/` 하위 경로라 루트가 아니다.

- `cjsdudwls1.github.io` 라는 이름의 저장소를 새로 만든다
- 거기에 `.well-known/assetlinks.json` 을 넣는다
- 내용의 지문(SHA-256)은 플레이에 AAB를 올린 뒤 Play Console의 앱 서명 키에서 복사한다
- 이 파일이 없어도 출시는 된다. 앱 상단에 주소창이 보일 뿐이다

실측 속도와 지구력 그대로의 동물 무리가 GPS로 쫓아온다. 소리만 듣고 도망쳐라.

### 자세한 설명

```
뒤에서 진짜 동물이 쫓아온다.

러너웨이는 위치 기반 러닝 게임입니다. 실제로 달리면 GPS가 내 위치를 읽고,
가상의 동물 무리가 지도 위에서 나를 향해 달려옵니다.

■ 실측 데이터 그대로

동물의 속도는 최고 시속이 아니라 실제 지구력 기준입니다.
치타는 25초 전력질주하고 3분을 쉽니다. 그래서 인간이 이길 수 있습니다.
닭은 시속 14킬로로 10초를 달리고 2분을 헐떡입니다. 생각보다 안 만만합니다.
프롱혼은 시속 88로 10분을 달립니다. 이건 못 깹니다.

사람은 스프린트에서 거의 모든 동물에게 집니다.
사람은 지구력에서 거의 모든 동물을 이깁니다.
그래서 이 게임은 빨리 달려 이기는 게임이 아니라, 적의 스프린트를 버텨내는 게임입니다.

■ 화면을 안 봐도 됩니다

이어폰을 끼면 소리로 위치를 압니다.
적이 왼쪽에 있으면 왼쪽에서 들립니다. 뒤에 있으면 둔탁하게 들립니다.
가까워질수록 자주 웁니다. 300미터에서는 10초에 한 번, 30미터 안에서는 거의 끊이지 않습니다.
소리가 안 끊기면 잡히기 직전이라는 뜻입니다.

음성은 행동을 바꿔야 하는 순간에만 나옵니다.
같은 상황이 반복되면 문장이 짧아지고 결국 소리만 남습니다.
말이 많아 귀찮아지지 않도록 30분에 스무 마디 남짓으로 묶여 있습니다.

■ 설치 없이도 됩니다

웹 주소로 바로 열립니다. 서버가 없어 위치 정보가 기기를 벗어나지 않습니다.
계정도, 로그인도, 광고도 없습니다.

■ 안전

차도와 횡단보도에서는 게임보다 신호를 먼저 보십시오.
이어폰 음량은 차 소리가 들리는 수준으로 유지하십시오.
```
