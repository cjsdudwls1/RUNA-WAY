# RunAway(가제) PRD v0.1

- 작성일: 2026-09-08
- 상태: 초안. 확정 결정 15건 + 질문지 추천 기본값 반영
- 근거 문서: [질문지](00-questionnaire.md), [리서치](01-research.md), [결정 로그](02-decisions.md)

## 1. 개요

### 한 줄 정의

- 지도에 뜬 가상의 추격자를 피해, 제한 시간 안에 목적지를 찍고 출발점으로 돌아오는 러닝 게임

### 해결하는 문제

- 1순위: 혼자 달리면 페이스를 못 올린다. 추격이 곧 인터벌
- 2순위: 러닝이 지루하다
- 러닝을 안 하는 사람에게는 "게임이니까 나가는" 이유를 제공

### 제품 정체성

- 러닝 위치기반 게임 앱
- 스토어 1차 카테고리: 건강·피트니스 (게임 카테고리 대형 IP 경쟁 회피)
- 게임산업법상 게임물로 인정하고 IARC 자체등급 이행

### 훅

- 내 위치와 가상 적의 위치가 같은 지도에 떠서 느끼는 현실감
- 스토어 영상 첫 5초: 적 아이콘이 내 아이콘 쪽으로 다가오는 실제 화면 녹화

### 타깃

- 전 범위. 러너는 더 즐기고, 비러너는 재밌게 시작
- 진입 설계: 최저 티어는 걷기-달리기 반복으로 클리어 가능
- 상단 설계: 최고 티어는 실제 인터벌 강도

## 2. 목표와 성공 지표

### 북극성 지표

- WAU당 주간 완주 세션 수
- 완주 세션 정의: 15분 이상 또는 1.5km 이상 + 목적지 도달

### 보조 지표

| 지표 | 12개월 목표 |
|---|---|
| MAU | 1만 |
| 4주 리텐션 | 20% |
| 주 2회 4주 유지율 | 측정 후 기준선 설정 |
| 유료 전환율 | 3~5% |
| 유료 사용자 | 1,000명 |

### 출시 게이트 (하나라도 미달이면 출시 보류)

| 항목 | 기준 |
|---|---|
| 배터리 | 30분 세션 8% 이하, 1시간 15% 이하 |
| 크래시 자유율 | 99% 이상 |
| 오판정 이의 제기율 | 세션당 5% 이하 |
| 거리 오차 | 실측 대비 ±2% |
| 방향 안내 정답률 | 현장 테스트 80% 이상 |

### 과훈련 가드레일

- 주간 러닝량 급증(전주 대비 +30% 초과) 시 경고
- 스트릭은 일 단위가 아닌 주 단위. 매일 뛰라고 압박하지 않음

## 3. 사용자

### 페르소나 A: 지루한 러너

- 20대 후반, 주 1~3회 5km, 나이키 런 클럽 사용
- 니즈: 같은 코스가 지겹다. 혼자서는 페이스를 못 올린다
- 성공: 셰퍼드 티어를 깨려고 자기 최고 페이스를 갱신

### 페르소나 B: 안 뛰는 사람

- 20대, 게임은 하지만 운동은 안 함. 3km도 힘듦
- 니즈: 운동 자체는 재미없다. 게임이면 나갈 수 있다
- 성공: 치와와 티어를 걷뛰로 클리어하고 도감 첫 칸을 채움

### 핵심 시나리오

1. 앱 실행 → 거리 선택(1/3/5km) → 티어 선택 → 시작
2. 출발 전 지도에 목적지와 적 초기 위치가 표시됨. 전체 확인 후 카운트다운
3. 달리는 중: 화면에 내 위치·적 위치·위협 게이지. 적이 접근하면 소리와 진동으로 경고
4. 갈림길에서 화면을 보고 경로 선택. 적이 뒤에 있으면 우회
5. 목적지 도달 → 출발점으로 복귀 → 완주
6. 결과 화면: 시간, 거리, 페이스, 피격 횟수, 티어 배지 → 공유 카드

## 4. 코어 게임 루프

### 세션 구조

- 형태: 루프형. 출발점에서 시작해 목적지 1~3개를 경유하고 출발점으로 복귀
- 이유: 세션이 끝난 곳이 곧 출발점이라 귀가 문제가 없음
- 마지막 10~15% 구간은 쿨다운. 적 비활성
- 워밍업: 시작 후 3분 무적. 적은 접근 연출만
- 프리셋: 1km / 3km / 5km. 자유 거리는 최대 10km

### 목적지 생성 (라우팅 API 미사용)

- 현재 위치 기준으로 목표 거리에 맞는 지점을 계산
- 직선거리 × 우회 계수(기본 1.3)로 실제 러닝 거리 추정
- 후보 필터
  - 지오펜스 배제: 군사시설 100m, 학교 50m, 차도 중앙, 사유지
  - 야간(일몰 이후): 사전 등록 화이트리스트(공원, 하천 산책로) 안에서만 생성
  - 물리적 도달 가능성: OSM 보행 가능 노드 기준
- 경로 안내 없음. 목적지 방향과 직선거리만 제공
- 이유: 보행자 경로 API가 월 5만원 예산에 맞지 않고, 길을 알려주면 공간 회피 판단이 사라짐

### 적 모델

- 공간 모델: 플레이어 궤적 추종. 도로망 그래프 불필요
- 적은 플레이어가 지나온 경로를 따라 추격
- 구성
  - 주 추격자 1: 후방에서 시작, 지속 추격
  - 매복자 1: 목적지 인근에 정적 배치. 상위 티어에서만
- 속도: 플레이어 최근 3세션 중앙값 페이스 기준 상대 속도 + 절대 상한
- 감지: 감지 반경 안에 들어오면 추격, 반경 밖 20초 지속 시 소멸 후 쿨다운 재스폰

### 잡힘 판정: 위협 게이지

- 진입 반경 40m, 이탈 반경 60m (히스테리시스로 경계에서 깜빡임 방지)
- 반경 내 체류 시 게이지 상승. 0 → 100%까지 5초
- 반경 이탈 시 상승 속도의 2배로 감소
- GPS 정확도 보정
  - accuracy 25m 초과: 게이지 상승 속도 50%
  - accuracy 40m 초과: "냄새 잃음" 상태. 적 정지, 게이지 동결
  - 세션 중 저신뢰 구간 10% 초과: 해당 기록 리더보드 비공개
- 게이지 100% 도달 = 피격 1회

### 피격과 실패

- 피격 1회: +30초 페널티, 적을 후방 200m로 재배치, 3초 무적
- 피격 3회: "탈출 실패" 표시
- 실패해도 러닝은 계속 가능. 거리·페이스 기록은 항상 저장
- 이유: 첫 세션 실패가 리텐션을 가장 크게 깎음. 운동은 끝까지 하게 함

### 정지 처리

- 자동 일시정지: 속도 0에 가까운 상태가 8초 지속되면 적도 정지
- 신호등 대기가 실력 차이가 되지 않게 함
- 정지 누적 상한 세션당 3분. 초과분은 경과 시간에 포함
- 리더보드 기록은 이동 시간 기준

### 스킬 축 (달리는 속도 외)

- 페이스 배분: 언제 스퍼트할지
- 갈림길 선택: 세션당 3~5회 결정 지점에서 경로 선택
- 안전지대 활용: 체크포인트에서 30~60초 회복
- 채택하지 않음: 스태미나 게이지(실제 체력이 스태미나), 니어미스 보너스(위험 행동 유도)

## 5. 난이도 티어

| 티어 | 동물 | 속도 배율 | 감지 반경 | 목표 포획률 | 대상 |
|---|---|---|---|---|---|
| 1 | 치와와 | 0.75x | 80m | 5% 이하 | 걷뛰 입문 |
| 2 | 진돗개 | 0.90x | 120m | 10~15% | 일반 러너 |
| 3 | 셰퍼드 | 1.00x | 150m | 20~25% | 주 2~3회 러너 |
| 4 | 늑대 | 1.10x | 180m | 30~35% | 경쟁 러너 |
| 5 | 사자 | 1.25x | 220m | 40~50% | 해금 조건 필요 |

- 속도 배율 기준: 플레이어 최근 3세션 중앙값 페이스
- 절대 하한: 티어별 최소 속도를 두어 느린 사용자에게도 게임이 성립
- 파라미터는 3개(속도 배율, 감지 반경, 지속 시간)만 표로 관리. 무리 크기·쿨다운은 파생값
- 승급: 자동 추천 + 상위 1단계까지 자유 선택. 사자만 해금 조건
- 밸런스 합격 기준: 실제 포획률이 목표 범위 안에 들어올 것

## 6. 러닝·피트니스

- 걷기 사용자 포함. 치와와 티어는 걷뛰 반복으로 클리어 가능
- 기준 페이스: 자기 보고 3단계(느림/보통/빠름) + 첫 3세션 자동 보정
- 판정용 현재 페이스: 5초 이동평균 + 30초 히스테리시스
- 심박: 안전 상한 용도만. 게임 판정에는 사용하지 않음
  - 나이 기반 상한(Tanaka 공식) 초과 시 경고 + 적 속도 자동 하향
  - 의료 조언이 아님을 고지, 끄기 옵션 제공
- Health Connect 연동: 워크아웃 쓰기 기본, 읽기는 최소. 삼성헬스는 Health Connect 경유
- 거리·페이스는 공식 러닝 기록 지위(±2% 오차 목표). 워치 연결 시 워치 값 우선
- 첫 세션 전 PAR-Q+ 7문항. 플래그와 동의 로그만 저장
- 과사용 방지: 소프트 상한 + 회복일 걷기 미션 인정

## 7. 지도·위치

### 지도 SDK

- 카카오맵 SDK
- 근거: 한국 보행 데이터 품질, 무료 한도(지도 일 30만 건), 안드로이드 공식 SDK
- 주의: 2026-07-21부터 계정당 첫 활성 앱만 무료. 이 앱이 첫 앱이어야 함
- 지도 계층은 인터페이스로 추상화. 글로벌 확장 시 Mapbox 교체 가능하게
- SDK 약관이 지도 위 게임 오버레이와 좌표 가공을 허용하는지 서면 확인 후 확정

### 적·경로 렌더링

- 적은 지도 SDK 마커가 아니라 자체 캔버스 오버레이에 2D 스프라이트로
- 이유: SDK가 바뀌어도 게임 표현이 유지됨
- 적 위치는 점이 아니라 "위협 반경" 원으로 표시. 판정 반경과 같은 크기
- 정확도 20m 초과 시 원이 흐려지며 "냄새 잃음"으로 전환. 화면과 판정 규칙이 일치

### GPS 파이프라인

1. 게이트 필터: accuracy 30m 초과, 타임스탬프 역행, 속도 8m/s 초과 폐기
2. 칼만 필터(등속 모델) 1Hz
3. 케이던스 정합: 150~190spm 범위 확인
4. GPS 소실 시 30초까지 데드레코닝, 이후 "냄새 잃음"
- 라우팅 스냅은 MVP에서 하지 않음. 자유 코스이므로 스냅 기준선이 없음

### 지오펜스

- MVP는 최소 DB + 수동 검증
- 군사시설 100m, 학교 50m, 차도 중앙, 신고된 위험 지점
- 목적지 생성 단계에서 배제. 런타임 진입 시에는 경고만
- 원격 차단 기능: 사고 신고된 지점을 서버에서 즉시 비활성화

## 8. UX

### 기본 플레이 상태

- 화면 켜짐. 폰은 손 또는 암밴드. 지도 상시 표시
- 무조작 15초 후 화면 디밍, 적 접근 시 자동 복귀
- 위급 정보는 화면 없이도 전달: 오디오 콜아웃 + 진동
- 안전 원칙: 화면을 봐야만 알 수 있는 정보는 실패로 직결되지 않는다
- 이유: 훅이 지도이고 회피가 공간 회피이므로 화면을 버릴 수 없음. 대신 이중화로 안전 확보

### 세션 화면 정보 위계

1. 위협 게이지 (최상단, 가장 큼)
2. 적 방향과 대략 거리 (5m 단위 반올림)
3. 목적지 방향과 남은 거리
4. 경과 시간, 현재 페이스
- 지도는 화면 중앙. 헤딩업 2D, 자동 줌
- 색은 색각 이상 안전 팔레트. 색 + 아이콘 + 진동 삼중 신호

### 온보딩

1. 설치 직후: 실내 시뮬레이션 데모 60초. 추격 오디오와 게이지를 바로 체험
2. 안전 고지 풀스크린 (첫 3회)
3. 권한 요청 순서
   - 위치(앱 사용 중) + 신체 활동: 첫 러닝 시작 직전
   - 알림: 첫 세션 완료 후
   - Health Connect, 카메라, 마이크: 요청하지 않음 (MVP)
4. 첫 세션: 5분 고정 스크립트. 어디서든 시작 가능한 미니 코스
- 활성화 지표: 설치 후 7일 내 첫 실외 세션 완료율

### 계정

- 게스트로 즉시 플레이. 생년월일만 로컬 저장
- 리더보드·공유 시점에 구글 로그인 요구
- 만 14세 미만 가입 불가

### 러닝 중 조작

- 필수 3종: 일시정지, 추격 끄기, 안내 반복
- 입력 경로: 화면 길게 누르기 1개 + 볼륨 버튼 + 잠금화면 알림 버튼
- 장갑·젖은 손 대비로 물리 버튼 경로 필수
- 음성 명령 미지원. 마이크 권한을 요청하지 않는 것이 심사에 유리

### 결과 화면

- 상단: 경로 히어로 이미지(정적)
- 게임 축과 러닝 축 병렬: 티어 배지·피격 횟수·페널티 시간 / 거리·페이스·시간
- 공유 카드: 9:16 정적 이미지. 동물 스탬프 + 시간 + 티어 + 마스킹된 경로 실루엣
- 판정 불만은 원탭 이의 제기로 흡수. 리뷰로 가지 않게 함

### 알림

- 사용자 지정 시각 리마인더
- 악천후 자동 취소
- 스트릭 위협형("연속 기록이 끊깁니다") 알림 금지

## 9. 오디오

### 최소 정보 집합 (화면 없이 전달)

- 적 상태: 접근 / 위험 / 이탈 / 냄새 잃음
- 목적지: 방향과 남은 거리
- 페이스: 목표 대비 빠름/느림

### 표현 방식

- 언어 콜아웃 + 비언어 강도 레이어 + 좌우 패닝·거리 감쇠
- 앞뒤 구분은 콜아웃과 로우패스 필터로 보완. HRTF 바이노럴은 미사용
- 방향 기준: GPS 진행 방향. 속도 1~2m/s 미만이면 방향 큐 보류하고 거리만 안내
- 골전도·오픈이어 이어폰 권장 문구를 온보딩에 포함

### 음성 생성

- 사전 생성 뱅크 방식. 실시간 TTS·LLM 미사용
- 화자: 오퍼레이터 1인 (무전 캐릭터). 존댓말
- 대사 수: MVP 150개 목표, 캐릭터당 최종 300라인
- 숫자 변수는 버킷 사전 생성 + 상대 표현 병행
- 대사 규격: 8어절 이하, 핵심어 선행, 중저역 EQ
- 우선순위: 안전 > 추격 > 목적지 > 코칭 > 잡담. 기본 발화 간격 8~10초
- 같은 대사는 세션 내 2회 이하
- 공급자: ElevenLabs와 Typecast에서 동일 대사 20개를 생성해 블라인드 청취 후 결정
- AI 생성 음성임을 온보딩 1회 + 설정 + 스토어 설명에 고지
- 대사는 스프레드시트로 관리하고 TTS 생성·번들을 스크립트로 자동화

### 음악 공존

- 사용자 음악 앱과 덕킹 기본. 설정에서 일시정지 선택 가능
- 앱 자체 BGM 없음. SFX + 로열티프리 앰비언트 2~3곡
- 오디오 엔진: Android Oboe 네이티브 직접 구현. 미들웨어 미사용

## 10. 소셜·리더보드

### 리더보드 구조

- 고정 코스가 없으므로 코스별 랭킹이 아닌 티어별 주간 랭킹
- 점수 = (완주 거리 × 티어 배수) - (페널티 시간 환산)
- 개인 기록은 거리별(1/3/5km) 페널티 포함 시간으로 별도 관리
- 티어별 분리. MVP는 3티어 공개(치와와·셰퍼드·사자)
- 초기 밀도 문제: 주간 참가자 20명 미만이면 전체 랭킹 비공개, 개인·친구 기록만 표시

### 공개 정책

- 기본 비공개. 가입 시 랭킹 참여 일괄 opt-in 유도
- 노출 정보: 닉네임, 시간, 티어, 피격 횟수
- 노출 금지: 원시 경로, 심박, 출발·도착 좌표
- 집 반경 300m 자동 마스킹 + 수동 프라이버시 존 추가

### 부정행위 방지 (MVP 범위)

- 1단 클라이언트 무결성: Play Integrity. 실패 시 플레이 허용, 랭킹 제외
- 2단 서버 물리 검증: 속도 상한, 순간이동, 케이던스 정합
- 자전거·차량 감지 시 즉시 중단이 아니라 기록 비공개 + 사유 안내
- 3단 리플레이 재시뮬레이션은 2차. 단 시뮬레이션 코어는 처음부터 결정론으로 작성
- 제재: 자동은 비공개까지. 계정 정지는 수동
- 이의 제기: 앱 내 폼 + 판정 리플레이 첨부

### 공유·바이럴

- 정적 결과 카드 + 딥링크가 MVP
- 경로 애니메이션 영상, 고스트 레이스, 초대 보상은 카드 공유율 확인 후 2차
- 친구: 코드/QR 기반 상호 친구
- 크루: 초대 코드, 1인 1크루, 상한 50명. 주간 상위 5명 합산

### 비목표 (1.0)

- 실시간 멀티플레이, 실시간 위치 공유, 사람 간 추격
- 자유 댓글, 채팅
- 지역(시/구/동) 랭킹

## 11. 안전

### 설계 원칙 (기능 결정의 필터)

1. 게임 규칙이 무단횡단, 차도 진입, 야간 전력질주를 보상하지 않는다
2. 화면을 봐야만 알 수 있는 정보는 실패로 직결되지 않는다
3. 달리는 중에 방향 결정을 강요하지 않는다. 결정 지점은 사전에 예고한다
4. 안전 기능은 절대 유료화하지 않는다

### 구현

- 자동 일시정지로 신호 대기가 불이익이 되지 않게
- 횡단 지점 전후 30m는 적 정지
- 야간(일몰 이후): 목적지 화이트리스트 적용, 추격 강도 자동 하향, 호러 오디오 레이어 off
- override 선택 시 고지 로그 저장
- 안전 고지: 첫 3회 풀스크린, 이후 카운트다운에 한 줄
- 긴급전화 버튼 + 신고 + 정지 감지 프롬프트
- 이어폰: 볼륨 상한 + 한쪽 귀 모드 옵션
- 접근성: 색각 이상 안전 팔레트, 대사 자막 로그, 시스템 글꼴 크기 대응

## 13. 기술

### 스택

| 영역 | 선택 | 근거 |
|---|---|---|
| 앱 | Kotlin + Jetpack Compose 네이티브 | 백그라운드 위치·배터리·오디오가 핵심 리스크 |
| 지도 | 카카오맵 SDK (추상화 레이어 경유) | 한국 품질, 무료 한도 |
| 위치 | FusedLocationProvider + Foreground Service | Android 14+ FOREGROUND_SERVICE_LOCATION 필수 |
| 오디오 | Oboe 네이티브 | 저지연, 미들웨어 불필요 |
| 시뮬레이션 | 순수 Kotlin 모듈 (고정 틱 1Hz, 정수 연산) | 서버·워치 이식 시 결과 일치 |
| 백엔드 | Supabase 서울 리전 무료 티어 | 인증·DB·RLS 한 번에, 월 0원 |
| 분석 | Sentry + PostHog 무료 티어 | 좌표는 전송하지 않음 |
| 라우팅 | 없음 | 예산 제약. 자유 코스 도입 시 Valhalla 자체 호스팅 검토 |

### 아키텍처 원칙

- 시뮬레이션 코어는 순수 함수 + 고정 틱 + 정수/고정소수 연산으로 격리
- 세션 시드를 기록해 결정론 재현 가능하게
- 위치 전송은 세션 종료 후 일괄 업로드만. 실시간 전송 없음
- 세션 로직과 음성 뱅크는 완전 오프라인 동작. 지도만 온라인 의존
- 지도 끊김 시 오디오 HUD로 세션 계속

### 데이터

- 로컬: Room. 세션 원시 트랙, 개인 기록, 도감
- 서버: 프로필, 세션 요약, 리더보드 엔트리, 검증 결과
- 밸런스 파라미터는 버전 번호가 붙은 JSON으로 원격 배포. 세션 기록에 버전 저장
- 텔레메트리 코어 이벤트를 첫 빌드부터: 추격 시작·탈출·포획 시점의 페이스, 적 거리, GPS 정확도, 티어

### 안드로이드 특이사항

- 삼성 배터리 최적화가 포그라운드 서비스를 종료시키는 문제
  - 첫 세션 전 배터리 최적화 예외 요청 다이얼로그 1회
  - 중단 감지 시 복구 가이드 표시
- Play 위치 권한 선언서 심사 리드타임 4주를 일정에 반영
- 최소 지원: Android 13+
- 듀얼밴드 GPS(L5) 기기 권장 안내. 도심 오차 40~60% 감소

## 16. 범위

### MVP 포함

- 안드로이드 단독
- 지도에 내 위치 + 적 1~2마리 실시간 표시
- 루프형 목적지 자동 생성 (1/3/5km)
- 위협 게이지 판정, 피격 페널티, 3회 실패
- 난이도 티어 5단계 (공개 랭킹은 3티어)
- 사전 생성 오디오 150개, 오퍼레이터 1인
- 결과 화면 + 정적 공유 카드
- 티어별 주간 리더보드 (Supabase, 게스트 + 구글 로그인)
- 부정행위 방지 1~2단
- Health Connect 워크아웃 쓰기
- 실내 시뮬레이션 데모 온보딩

### MVP 제외

- 카메라 AR (전면 제외)
- 워치, 스마트 글래스
- iOS
- 실시간 멀티플레이, 고스트 레이스, 크루
- 실시간 TTS·LLM 내레이션
- 스토리 미션, 기지 건설, 시즌패스
- 결제 (베타 무료)
- 트레드밀·실내 모드
- 사용자 제작 코스
