## 두 아이디어에서 읽히는 패턴 (다음 발상 전에 걸 필터)

두 아이디어에서 읽히는 패턴은 동일하다: (a) 발상의 출발점이 '내가 소비자로서 느낀 사소한 귀찮음·재미'(캔디)이고, (b) 핵심 재료가 남의 것(중계권 영상·지도·게임 IP 기대 수준)이며, (c) 매일 쓰는 습관성 앱 구조라 무료 선점자와 정면 충돌하고, (d) '경쟁 공백'을 검색 없이 가정했다 — 실제로는 두 건 모두 스토어·Show HN·구글 30분 검색으로 동일 루프 5개 이상이 나왔다. 반대로 생존한 3개(논문·청첩장·견적서)는 전부 '남의 의례·업무 절차'에서 나왔고, 산출물을 유저가 소유하며, 마감이 외부에서 강제되고, 건별로 돈이 이미 오간다. 또 하나의 메타 교훈: 분석가의 피벗 2건이 모두 회의론자에게 죽었다 — 피벗은 원안보다 검증이 느슨해지는 경향이 있으므로 피벗에도 원안과 같은 실명 경쟁자 리스트를 요구해야 한다. 다음 발상 시 코드는 물론 분석에 들어가기 전에 다음 5개 필터를 순서대로 걸어라. ① 권리자 필터: 이 서비스의 핵심 재료(영상·데이터·IP·위치)의 소유자가 나 또는 유저인가? 제3자면 즉시 탈락. ② 실명 30분 필터: 플레이스토어·앱스토어·Show HN·네이버에 핵심 키워드 3개를 검색해 동일 루프가 3개 이상이면 '경쟁 공백' 주장 금지, 5개 이상이면 탈락. ③ 데드라인 소유자 필터: 유저가 스스로 마감을 갖는가(제출·결혼·입찰·신고·이사)? 취미·오락·습관은 마감이 없으므로 탈락. ④ 산출물 소유 필터: 결과물이 유저 손에 남는 자산(문서·초대장·견적서·인쇄물)인가, 아니면 남의 콘텐츠를 보는 경험인가? 후자면 탈락. ⑤ 지불 이유 필터: 돈이 '귀찮음 해소'가 아니라 '창피·불합격·거래 실패 회피'에서 나오는가? 전자면 캔디. 발상 원천 자체도 바꿔라 — '내가 좋아하는 것'이 아니라 '남이 돈 내고 겪는 절차'(대학원 행정, 예식, 관공서 서류, 소규모 사업자의 견적·계약·정산)에서 출발하면 필터 ①③④가 자동으로 통과된다.

## 2. 소크라테스식 전제 검증

### Q1. 러닝 붐이면 러닝 '게임'에 돈을 낼까? 러너의 돈은 지금 어디로 흐르는가?

돈은 대회 참가비와 장비로 흐른다. 서울마라톤 풀코스 10만원(재킷 패키지)·10km 7만원, 한강 서울 하프 5만원, 마라톤 참가자 100만 명 돌파, 러닝 바람막이 거래액 513% 급증, 안다르 2Q25 매출 891억. 반면 앱 결제는 런데이 연 2.9만원이 국내 수용 상한이고, 스트라바가 2025년 3월 한국 스토어에서 철수(KISA의 접근권한 동의 시정 요구 거부)했을 때 한국 러너들의 반응은 '국산 유료 앱으로 이동'이 아니라 VPN·APK 우회였다. 게임형 러닝앱의 세계 1위 Zombies, Run!조차 2022년 유료 구독자 4만 명·연매출 A$1.2M에 그친다. 러너는 '기록·완주·메달'에 지불하지 '몰입 연출'에 지불하지 않는다.

### Q2. '지도 위 실제 지형에 적 배치'는 Zombies, Run!에 없는 진짜 차별점인가, 아니면 그들이 일부러 버린 기능인가?

일부러 버린 기능에 가깝다. Zombies, Run!의 추격은 지도 좌표가 아니라 '직전 30초 평균 페이스 대비 +20%를 100초 유지'라는 상대 속도 판정이다. 이유는 GPS다: 스마트폰 GPS는 개활지 중앙 오차 2.7~7.3m지만 도심 빌딩 사이에서는 20~50m 오차·12.7% 신호 손실이 난다. 30m 뒤에 좀비를 배치하면 오차만으로 '잡힘' 오판이 생긴다. 이데일리 기자 체험(2025.10)에서도 3km 달렸는데 앱은 0.27km로 기록하는 GPS 버그가 보고됐고 구글플레이 평점 3.5(리뷰 2.6만)에 GPS 불만이 반복된다. 게다가 '지도 위 좀비 스폰+탈출 지점+리더보드'는 2026년 8월 무료 브라우저 게임 Run With Zombies가, 'GPS 위 좀비 무리'는 Zombie Streets GPS 등이 이미 구현했다. 실명 검색 결과: 경쟁 공백이 아니다.

### Q3. 13년 운영·1,000만 다운로드 카테고리 1위가 왜 2025년에 '고액 6자리(100만 달러 미만)'에 팔렸나?

카테고리 천장이 낮기 때문이다. 2021년 OliveX가 Six to Start를 950만 달러에 인수(MAU 30만, 구독자 5만, ARPU 연 £25+)했지만 2022년 실적은 MAU 8.2만·유료 4만·연매출 A$1.2M. 2025년 3월 직원 2명만 남기고 전원 해고, 2025년 11월 24일 원작자 나오미 앨더먼이 '고액 6자리'에 되사감. 라이선스 스핀오프 Marvel Move도 종료. 즉 '오디오 추격 러닝 게임'의 전 세계 시장이 연 10억 원 남짓이고, 한국어 한정 1인 개발자의 도달 가능 상한은 그 5~10%(연 5,000만~1억원)로 봐야 한다. 이 시장에서 '느리지만 단단하게' 자랄 토양이 없다.

### Q4. 리더보드는 경쟁을 만들까, 치팅과 콜드스타트 문제를 만들까?

둘 다 후자다. 페이크 GPS 앱은 구글플레이 설치 1,000만+·평점 4.6이며 조이스틱·경로 시뮬레이션·속도 제어까지 지원한다. Niantic은 전담 안티치트 팀으로 '순간이동·비현실적 속도' 탐지를 돌리는데, 1인 개발자의 공개 리더보드는 첫 스푸퍼 한 명에 무너진다. 콜드스타트도 치명적: 이용자 300명인 리더보드는 동기가 아니라 공허함이다. 인스타 공유용 '기록 카드' 이미지가 리더보드보다 싸고 안전하다.

### Q5. 이 아이디어는 확정 교훈 (3) '이벤트성 수요 × 건별 결제'인가, '습관성 구독'인가? 바꿀 수 있는가?

원안은 전형적 습관성 구독(매일 뛸 때마다 쓰는 앱)이고, 무료 선점자(NRC 가이드런, Run With Zombies, 런데이 무료 구간)가 버티고 있어 교훈 (3)대로 죽는다. 바꿀 수는 있다: 한국에는 이미 '기간 한정 버추얼 런 + 완주 메달'이라는 돈이 흐르는 형태가 있다(랭킹마라톤의 애니멀런·비대면 마라톤, 위런위로 버추얼 런, RUN for the MOON 기부런의 완주 메달+키트, 2026 디즈니런 버추얼런; 커뮤니티 대회 참가비 1~3만원). '4주 한정 좀비 서바이벌 버추얼 런(참가비+메달)'으로 바꾸면 데드라인·건별 결제·니치 테마가 모두 성립하고, GPS 엔진·위치정보 수집·리더보드 스푸핑이 통째로 사라진다.

## 4. 수익모델 시나리오

### 1) 앱 구독(원안): 좀비/맹수 모드·시즌 전체 이용권

- **가격:** 월 4,900원 / 연 29,000원(국내 수용가 2,900~6,900원 대역, 런데이 연 2.9만원과 동일선). Zombies, Run!의 월 9,900원보다 낮게 잡아야 비교 시 명분이 생김
- **월 수익 추정:** 보수 약 17만원 / 현실 약 83만원 / 낙관 약 833만원 (정상상태 도달까지 6개월+)
- **근거:** 계산식 = 월 설치 × 결제전환 2% ÷ 월 이탈 15%(정상상태 구독자) × 4,900원 × 0.85(스토어 수수료 15%). 보수: 설치 300/월 → 신규 6/월 → 정상 40명 → 19.6만 → 17만원. 현실: 설치 1,500/월 → 정상 200명 → 98만 → 83만원. 낙관: 릴스 바이럴로 설치 10,000/월 지속 → 정상 2,000명 → 980만 → 833만원. 낙관 전제는 2주 실측 채널이 없어 근거 없음(교훈 4). 세계 1위가 유료 4만 명이므로 한국 1인 앱의 현실 상한은 구독 수백 명.

### 2) 건별 IAP: 시즌/모드 단품 판매(사자 모드, 시즌2 에피소드 팩)

- **가격:** 모드 3,300원, 시즌 팩 5,500원(웹 결제 유도 시 수수료 0.8~3.4%, 인앱은 15%)
- **월 수익 추정:** 보수 약 4만원 / 현실 약 17만원 / 낙관 약 110만원
- **근거:** 계산식 = 월 설치 × 구매전환 3% × 4,400원 × 0.85. 보수 300 → 9건 → 4만원. 현실 1,500 → 45건 → 17만원. 낙관 10,000 → 300건 → 110만원. 재구매를 만들려면 시즌마다 대본+음성 2~3주 제작이 필요 → '매일 갈아넣는 구조'로 변질. Zombies, Run!이 2015년 단품(레거시 33,000원)에서 구독으로 전환한 이유가 바로 이것.

### 3) 광고(무료 이용자 대상, 러닝 전후 배너·보상형)

- **가격:** DAU 1,000당 월 10~150만원 벤치마크
- **월 수익 추정:** 보수 약 1만원 / 현실 약 8만원 / 낙관 약 60만원
- **근거:** DAU = 정상 활성자(설치×D30 10%). 보수 DAU 30, 현실 DAU 150~500, 낙관 DAU 1,000+. 러닝 중 광고는 UX 자해이고 러닝 전후 노출은 세션당 1~2회에 그쳐 하한 계수 적용. 사실상 무의미.

### 4) 피벗: '좀비 서바이벌 버추얼 런' 기간 한정 이벤트(참가비 건별 결제 + 완주 메달·기록증 + 추격 오디오 미션 MP3)

- **가격:** 참가비 19,000원(얼리버드 15,000원), 크루 10명 이상 단체 10% 할인. 웹 결제(토스페이먼츠/스마트스토어) 수수료 ~3.4%
- **월 수익 추정:** 보수 약 57만원 / 현실 약 113만원 / 낙관 약 377만원 (분기 1회 이벤트를 월 환산)
- **근거:** 이벤트당 순익 = 참가자 × 19,000 × 0.966 − 참가자 × 7,000원(메달·포장·배송 원가). 보수 150명 → 275만 − 105만 = 170만원/이벤트 → 월 57만. 현실 300명 → 550만 − 210만 = 340만원 → 월 113만. 낙관 1,000명 → 1,835만 − 700만 = 1,135만원 → 월 378만. 지불 증거: 커뮤니티 러닝 대회 참가비 1~3만원, 런포더문·랭킹마라톤·위런위로가 같은 형태로 판매 중, 마라톤 참가자 100만 명. 메달 MOQ(100~300개, 개당 3,000~7,000원) 재고 리스크는 '마감 후 주문 제작'으로 제거.

## 5. MVP 설계

**핵심 가설:** 한국 20~30대 러너는 '기간 한정 추격 서사 + 완주 메달'에는 1.5~2만원을 건별로 내지만, 매일 쓰는 추격 게임 앱 구독에는 내지 않는다. (원안 가설 '지도 위 적 배치가 결제를 만든다'는 검증 전에 이미 무료 클론과 GPS 오차 데이터로 기각)

**코드 전 검증:** 코드 없이 2주 실측(교훈 4): ① 랜딩+사전 결제 페이지(얼리버드 15,000원, 미달 시 전액 환불 명시)를 Threads 러닝 계정·디시 러닝 갤러리·러닝크루 오픈채팅 5곳·인스타 릴스(추격 사운드 15초 데모)에 배포. ② 합격선: 14일 내 실결제 30건(45만원) 또는 단체 크루 2팀. 15건 미만이면 드랍. ③ 동시에 Zombies, Run! 한국 리뷰 2.6만 건 중 한국어 리뷰를 긁어 '지도/시각화 요구'가 실제로 있는지 정량화. ④ 메달 제작업체 2곳 견적(MOQ·단가·리드타임)을 결제 전에 확보해 원가 7,000원 가정을 검증.

**최소 기능:**
- 웹 랜딩 1장(이벤트 소개·메달 실물 렌더·일정·참가비) + 사전 결제 링크(토스/스마트스토어)
- 추격 오디오 미션 MP3 3편(한국어, ElevenLabs로 사전 생성·편집, 각 20~30분: 치와와/늑대/사자 난이도 = '지금부터 100초 동안 +10/20/30% 가속' 상대 페이스 지시)

## 6. 기술

- **스택:** 1단계: Next.js(또는 Astro) 정적 랜딩 + 토스페이먼츠/네이버 스마트스토어 결제 + 타입폼/구글폼 인증 + Supabase(참가자·기록) + ElevenLabs Creator($22/월, 제작 달만) + Audacity 편집 + Canva/Sharp로 기록 카드 자동 생성. 2단계 앱: Flutter + flutter_background_geolocation(포그라운드 서비스 type=location, FOREGROUND_SERVICE_LOCATION 선언, ACCESS_BACKGROUND_LOCATION 미요청) + 네이버 지도 SDK 또는 Mapbox 무료 티어 + just_audio(음악 앱과 오디오 덕킹) + RevenueCat(단품 IAP) + Supabase.
- **월 고정비:** 1단계 월 0~3만원(도메인·Supabase 무료·ElevenLabs $22는 제작 달만) + 이벤트당 메달 원가(참가자×7,000원, 마감 후 주문). 2단계 앱 월 3~8만원(플레이 등록 $25 1회, Mapbox/네이버 지도 무료 티어, Supabase Pro $25 필요 시).
- **어려운 부분:**
  - GPS 노이즈: 도심 오차 20~50m·신호 손실 12.7% → 좌표 기반 추격 판정은 불가, 속도 필터(칼만/이동평균)로 페이스만 판정하고 지도 위 적은 '연출'로 격하해야 함
  - 배터리·백그라운드: 연속 GPS 8~12%/h, 삼성 등 제조사 앱 절전이 포그라운드 서비스를 죽이는 케이스 → 기기별 CS가 1인에게 집중(Zombies, Run!의 GPS 불만 리뷰가 그 미래)
  - 목표 지점 자동 지정의 안전성: 차도·횡단보도·강변 막다른 길 회피 → 보행자 경로 API(카카오/네이버) 의존, 실패 시 사고 책임 문제
  - 오디오 엔진: 블루투스 지연, 음악 앱과 공존, 화면 꺼진 상태 재생 지속
  - 스푸핑 방지: 페이크 GPS 앱(설치 1,000만+) 대응 불가 → 리더보드 자체를 빼는 설계 결정
  - 구글플레이 정책: FGS 타입 선언·위치 권한 사용 근거 영상 제출, 심사 3~5일, 2025년 4분기 위치 권한 과다로 4만 앱 거절
  - 정보통신망법 접근권한 개별 동의 화면(스트라바 철수 원인) 구현
  - 콘텐츠 제작 파이프라인: 시즌마다 대본·음성·SFX 제작이 반복 노동

**분석가의 피벗 제안:** '좀비 서바이벌 버추얼 런' — 분기 1회, 4주 한정 이벤트. 참가비 19,000원(얼리버드 15,000원, 크루 10명+ 10% 할인), 완주 메달(마감 후 주문 제작, 원가 7,000원)+PDF 기록증+인스타 기록 카드. 콘텐츠는 한국어 추격 오디오 미션 MP3 3편(치와와/늑대/사자 = +10/20/30% 가속 100초 유지, ElevenLabs 사전 생성·편집)이며 러너는 런데이·NRC 등 기존 앱으로 뛰고 스크린샷으로 인증한다. 이렇게 하면 GPS 엔진·배터리·위치정보법 신고·플레이스토어 위치 심사·리더보드 스푸핑·구독 이탈이 전부 사라지고, 웹 결제 수수료 3.4%로 스토어 15%를 피한다. 실명 경쟁자는 랭킹마라톤(애니멀런·비대면 마라톤), 위런위로 버추얼 런, RUN for the MOON, 디즈니런 버추얼런이며 이들은 서사·오디오 미션이 없는 '메달 판매'라는 점이 차별 여지다. 검증 순서: ① 메달 업체 2곳 견적(MOQ·단가·리드타임) ② 랜딩+사전 결제 2주(Threads 러닝 계정, 디시 러닝 갤러리, 크루 오픈채팅 5곳, 릴스 15초 사운드 데모) ③ 실결제 30건 또는 크루 2팀이면 1회 운영, 15건 미만이면 드랍. 1회 흑자(순 170만원+)가 확인되면 그때 '지도 위 적'을 시각 연출로만 넣은 안드로이드 앱을 2단계로 검토한다.

## 9. 적대적 검증 — 회의론자의 반박

**판정: 보류/드랍** — 원안(지도 위 적 배치 러닝 AR 게임)은 분석가의 판정대로 죽었고, 그 근거(Zombies, Run! 2022년 A$1.2M·유료 4만, 2025년 전원 해고 후 high six-figure 매각, 이데일리 GPS 오류 체험기, 무료 브라우저 클론 Run With Zombies의 2026년 8월 등장)는 전부 검증됐다. 문제는 피벗이다. '기간 한정 좀비 서사 + 오디오 미션 + 메달 + 리더보드'는 Zombies, Run!이 18회째 파는 Virtual Race 그 자체이고, 국내에서는 애니멀런(러닝포인트/랭킹마라톤)이 월별 동물 테마 메달을 15,000~25,000원에 팔며 8,000명을 동원하는 데다, 같은 플랫폼에서 누구나 비대면 대회를 개설하고 메달을 주문할 수 있어 '이벤트 운영이라는 비-LLM 마찰'조차 커머디티다. 스크린샷 인증 구조에서는 오디오 미션 수행을 판정할 수 없어 게임성이 사라지고, '좀비런' 이름은 커무브(2013~ 국내 최대 좀비 페스티벌)와 Zombies, Run!의 국내 통칭이 이미 점유했다. 2026년 버추얼런 매진 사례는 디즈니런·무한도전 런 같은 IP 이벤트뿐이고, 무명 1인 주최를 위한 채널 실측·자산은 없다. 산식도 얼리버드 15,000원·배송비·소량 메달 단가·부가세·환불을 반영하면 이벤트당 순익 100만원 안팎(월 30~35만원)으로 내려앉는다. 확정 교훈 (1)(2)(4)에 피벗도 걸리므로 '피벗 필요'가 아니라 '보류/드랍'이 맞다. 굳이 살리려면 코드 없이 랭킹마라톤 플랫폼 개설로 수요를 재고, 상표·메달 견적·채널 자산이 확인된 뒤에만 현역 3개 뒤에 줄을 세워라.

### 반박 1 [결정적]

- **주장:** 피벗의 차별 여지: 국내 버추얼런(랭킹마라톤·위런위로·런포더문·디즈니런)은 '서사·오디오 미션 없는 메달 판매'라서 '좀비 추격 서사 + 오디오 미션 + 메달' 조합은 비어 있다.
- **반박:** 비어 있지 않다. 카테고리 1위 Zombies, Run!이 바로 그 상품을 2015년부터 팔아왔다: 'Virtual Race'는 기간 한정·정해진 거리·레이스 번호·실물 메달·리더보드에 전용 스토리 오디오 미션을 묶은 유료 이벤트로, 이미 18회째(VR17 'Running on Fumes', VR18 'Circuit Breaker' 2025년 1월 공지, zrx.app/enter/VR18, shop.zombiesrungame.com 메달 팩)이고 한국어 시즌1 더빙 앱 위에서 돌아간다. 국내에서는 러닝포인트의 애니멀런이 '매달 새로운 동물 테마 + 메달·뱃지·스티커 + WWF 기부 + 인증사진 제출 → 기록증'을 15,000~25,000원에 월 단위로 판매 중이며(animallace.com, 이투뉴스/뉴데일리), 2025년 10월 오프라인 애니멀런 서울에 8,000명을 모았다(ABC뉴스). 원안의 '동물 단계별 난이도' 테마조차 브랜드로 선점돼 있다. 피벗은 '경쟁 공백'이 아니라 세계 1위와 국내 1위의 정중앙이다.

### 반박 2 [강함]

- **주장:** 피벗의 해자는 앱이 아니라 '이벤트 운영·메달 실물·커뮤니티 동원'이라는 비-LLM 마찰에서 나온다.
- **반박:** 그 마찰은 이미 상품화되어 누구나 살 수 있다. 랭킹마라톤은 '전 세계 어디서 누구나 비대면 마라톤 대회 개설 및 참가 가능'을 내건 플랫폼이고(구글플레이/앱스토어 설명, letspl 부스), 앱 GPS 자동 기록·실시간 랭킹까지 제공하며, 같은 회사가 '마라톤 메달 제작 서비스'를 별도 사업으로 운영한다(공감신문, rankingmarathon.com/medal). 즉 1인 개발자가 3주 걸려 만들 '랜딩+결제+스크린샷 인증+메달 발주' 파이프라인은 기존 플랫폼에서 클릭 몇 번으로 개설되는 커머디티이고, 선점자는 '이번 달 테마 = 좀비'로 바꾸는 데 한 달이면 된다. 확정 교훈 (2)의 '비-LLM 마찰' 요건을 피벗도 충족하지 못한다.

### 반박 3 [강함]

- **주장:** '추격 오디오 미션 MP3 3편(치와와/늑대/사자 = +10/20/30% 가속 100초)'이 피벗의 게임성·차별 콘텐츠다.
- **반박:** 인증이 '런데이·NRC·삼성헬스 스크린샷 수동 검수'인 구조에서는 오디오 미션을 들었는지, 가속 구간을 지켰는지, '잡혔는지'를 판정할 방법이 없다. 결과적으로 참가자가 받는 실제 상품은 애니멀런과 동일한 '메달+기록증'에 팟캐스트 3편이 딸린 것이고, '쫓긴다'는 핵심 JTBD는 게임 판정이 사라진 순간 소멸한다. 게다가 '음성으로 페이스를 올리라고 지시하는 인터벌 오디오'는 NRC가 300개 이상 무료 가이드런(인터벌 포함, 한국어 코치)으로 제공하고, 런데이는 '가상 러너들과 경쟁하는 가상마라톤·실시간 비대면 대회' 기능을 이미 내장했다(앱스토어 설명). 차별 콘텐츠가 무료 선점자의 기본 기능과 겹친다.

### 반박 4 [강함]

- **주장:** 이벤트당 순익 = 참가자 × 19,000원 × 0.966 − 참가자 × 7,000원 → 보수 150명 170만원/이벤트, 월 환산 57만원.
- **반박:** 산식이 자기 설계와 모순된다. ① 분석가 스스로 검증 합격선을 '얼리버드 15,000원 30건'으로 잡았으니 초기 매출의 대부분은 15,000원이고, 크루 10% 할인까지 겹치면 실효 단가는 13,500~16,000원이다. ② '메달·포장·배송 7,000원'에서 국내 택배 3,000~4,000원을 빼면 메달+리본+케이스+기록증 원가가 3,000~4,000원이어야 하는데, 검색된 국내 업체(인쇄랑·이모션아트·예스폼기프트·빅토리컵·메달오브피니셔)는 전부 '견적 문의'이며 100~300개 소량 단가 근거가 없다. ③ 통신판매업 신고(직전연도 거래 50회 미만 또는 간이과세자만 면제), 부가세, 청약철회(용역 7일) 환불, 불량 재발송이 빠져 있다. 재계산: 150명 × 15,500원 × 0.966 ≈ 225만 − 150명 × 8,500원(원가+택배 현실치) ≈ 127만 − 세금·환불·불량 ≈ 100만원 안팎. 분기 1회면 월 30~35만원이고, 이것도 150명이 모인다는 전제다.

### 반박 5 [강함]

- **주장:** CAC≈0 채널: Threads 러닝 계정·디시 러닝 갤러리·크루 오픈채팅 5곳·릴스 15초 데모로 14일 내 실결제 30건.
- **반박:** 채널이 아니라 희망 목록이다. 개발자에게 기존 팔로워 자산이 있다는 언급이 없고, Threads는 외부 링크 포함 글의 도달을 억제하며 첫 1시간 반응으로 도달을 결정한다(아이보스·스레드 운영자 후기). 디시 마이너 갤러리와 크루 오픈채팅은 외부 결제 링크 홍보를 관행적으로 삭제·강퇴한다. 반대 증거는 명확하다: 2026년 버추얼런에서 팔린 것은 디즈니런 버추얼(65,000~80,000원, 즉시 매진, 스포츠서울·디즈니코리아 주최)과 무한도전 런(99,900원, 1~2분 매진) 같은 IP·언론사 주최 이벤트다. 수요는 '테마'가 아니라 '브랜드·IP·주최자 신뢰'에 쏠리며, 무명 1인 주최의 19,000원 이벤트가 그 사이에서 150명을 모은다는 실측 근거가 전혀 없다. 확정 교훈 (4)에 의해 이 채널은 0으로 계산해야 한다.

### 반박 6 [강함]

- **주장:** '좀비 서바이벌 버추얼 런'이라는 네이밍·테마로 니치를 잡는다.
- **반박:** 한국에서 '좀비런'은 이미 두 선점자의 이름이다. 커무브(Kommove)의 '좀비런'은 2013년부터 서울랜드에서 열린 '국내 최대 좀비 페스티벌'로 티몬과 함께 2013·2014 할로윈 에디션 연속 완판, 인천·부산 확장, 티켓링크·타임티켓 판매, 페이스북 zombierun.korea 운영 이력이 있고(스포츠경향·이데일리·온오프믹스), 이데일리는 2025년 10월 Zombies, Run! 체험기 제목에도 '러닝앱 좀비런'을 썼다. 검색 노출과 상표 모두 선점됐을 가능성이 높으며(KIPRIS 미확인 — 확인 전 사용 불가), 원안의 유일한 검색 키워드 '좀비+러닝'은 SEO/ASO에서 처음부터 3순위 이하다.

### 반박 7 [약함]

- **주장:** 한국 러닝 인구 1,000만(추정), 참여율 7.7%.
- **반박:** 7.7%는 문화체육관광부 국민생활체육조사(2025) 수치로 맞지만, 같은 기사들이 이를 '약 300만 명 이상'으로 환산한다(세계일보·쿠키뉴스). '1,000만'은 언론 헤드라인용 추정이며 두 숫자를 나란히 쓰면 시장 규모가 3배 부풀려진다. 마라톤 대회 참가자 100만 명(2024년 254개 대회, 우먼타임스)은 연인원이므로 중복 참가를 감안하면 실인원은 그보다 훨씬 적다.

### 반박 8 [약함]

- **주장:** 법적 리스크: 1단계는 위치정보를 수집하지 않으므로 사실상 위험 0에 가깝다.
- **반박:** 위치정보법은 피했지만 상거래 규제를 통째로 빠뜨렸다. 비대면 참가비 판매는 통신판매에 해당하며 신고 의무(면제: 직전연도 거래 50회 미만 또는 간이과세자)가 있고, 참가비는 용역이라 청약철회 시 즉시 환불 규정이 적용되며(전자상거래법), 메달 배송을 위한 이름·주소·전화번호 수집은 개인정보처리방침·수탁자(택배) 고지가 필요하다. 소상공인/1인 창조기업 위치정보 특례(개시 후 1개월 내 신고)는 확인됐으나, 2단계 앱에서 리더보드 없이 '기록 카드 이미지'만 공유해도 서버에 경로가 올라가는 순간 신고 대상이 된다는 분석가의 판단은 옳다. 치명적이진 않지만 '위험 0'은 아니다.

### 반박 9 [약함]

- **주장:** 원안의 시장 상한 근거: Zombies, Run! 2022년 연매출 A$1.2M·MAU 8.2만·유료 4만, 2025년 3월 전원 해고, 11월 원작자가 '고액 6자리'에 인수.
- **반박:** 반박 불가 — 검증 결과 모두 사실이다. OliveX 2022 투자 자료에 A$1.2M/82,000 MAU/40,000 구독/860만 다운로드가 명시돼 있고, 2021년 인수 당시(MAU 30만·구독 5만·ARPU £25+)보다 이미 급감한 상태였다. PocketGamer.biz가 2025년 3월 2명 제외 전원 해고를, 여러 매체가 2025년 11월 high six-figure 재인수를 보도했다. 이데일리 기자 체험의 GPS 오류(15분 러닝: 갤럭시워치 3km vs 앱 0.27km)도 확인됐고, Run With Zombies는 Hacker News에 약 한 달 전(2026년 8월경) 무료 브라우저 GPS 좀비 게임으로 올라온 것이 맞다. 원안 사망 판정은 정확하다.

### 치명적 결함

- 피벗 상품('기간 한정 좀비 서사 + 오디오 미션 + 실물 메달 + 리더보드')은 카테고리 1위 Zombies, Run!이 2015년부터 18회째 판매 중인 'Virtual Race'와 동일하며, 국내에서는 애니멀런(월별 동물 테마 메달·15,000~25,000원·8,000명 오프라인 동원)이 같은 형태를 월 단위로 팔고 있다. 확정 교훈 (1) '경쟁 공백은 기본적으로 허위'가 피벗에도 그대로 적용된다.
- 피벗의 유일한 차별 요소(추격 오디오 미션)는 스크린샷 인증 구조에서 수행 여부를 판정할 수 없어 게임성이 0이 되고, 남는 상품은 '메달+기록증+MP3' — 랭킹마라톤에서 누구나 개설 가능한 커머디티다. 비-LLM 마찰(교훈 2)이 없다.
- 채널이 실측은커녕 자산도 없다. 2026년 버추얼런 시장에서 매진된 것은 디즈니런(65,000~80,000원)·무한도전 런(99,900원) 같은 IP·언론사 주최 이벤트뿐이며, 무명 1인 주최 19,000원 이벤트가 150명을 모은다는 근거는 없다(교훈 4).
- '좀비런' 브랜드는 커무브(2013~ 국내 최대 좀비 페스티벌)와 Zombies, Run!의 국내 통칭이 이미 점유했고 상표 등록 여부가 미확인이다.
- 수익 산식이 자기 설계(얼리버드 15,000원 기준 검증)와 모순되며, 배송비·소량 메달 단가·부가세·환불을 반영하면 보수 케이스 순익은 이벤트당 100만원 안팎, 분기 1회 → 월 30~35만원 수준으로 현역 3개 프로젝트의 기회비용을 정당화하지 못한다.

### 진행 조건 (굳이 살리려면)

1. KIPRIS에서 '좀비런'·'ZOMBIE RUN' 상표(41류 스포츠·오락 행사, 9류 앱)를 조회해 커무브·Zombies Run Ltd 등록 여부를 확인하고, 등록돼 있으면 명칭·테마를 즉시 폐기한다.

5. 통신판매업 신고(또는 면제 요건 해당 여부), 전자상거래법 청약철회·환불 정책, 배송용 개인정보처리방침을 판매 페이지 공개 전에 갖춘다.
6. 현역 3개(논문서식 클리닉·모바일 청첩장·현장견적) 중 하나라도 2주 실측이 진행 중이면 이 아이디어에 시간을 쓰지 않는다. 위 조건을 모두 통과해도 우선순위는 4위 이하다.

## 2. 소크라테스식 전제 검증

### Q1. '구단 계정을 하나하나 찾아봐야 귀찮다'는 전제가 사실인가? 경기 하이라이트는 정말 10개 구단 채널에 흩어져 있나?

아니다. 경기 하이라이트의 단일 공식 소스는 TVING SPORTS 유튜브 채널(45.8만 구독, 3,144편)이며 전 경기를 경기 종료 후 매일 올린다(예: '[KIA vs NC] 9/2 경기 I 2026 신한 SOL KBO 리그 I 하이라이트 I TVING'). KBO 공식 채널(26.2만)도 하이라이트를 게시한다. 구단 채널(한화 이글스티비 52.4만 등)의 주력은 경기 하이라이트가 아니라 브이로그·인터뷰·응원 콘텐츠다. 즉 '귀찮음'의 실체는 흩어진 콘텐츠가 아니라 사용자가 TVING SPORTS 채널을 구독+알림 설정하지 않은 것뿐이다. 문제 정의 자체가 틀렸다.

### Q2. '저작권이 좀 빡세겠다'가 아니라 권리자가 누구이고 무엇까지 막는가? 1인 개발자가 설 자리가 조금이라도 있나?

KBO 유무선(뉴미디어) 중계권은 CJ ENM 티빙이 2024~2026(3년 1,350억) 독점, 2025-11-18 우선협상 타결로 2027~2031년 5년 연장(연 약 900억)까지 확정됐다. 권리 범위는 생중계+하이라이트+VOD 전부. 팬의 2차 창작은 '40초 미만·비상업적'만 허용되며, 2025년 6월 티빙이 수익화 숏폼을 대대적으로 단속했고 2019년에는 KBO가 구단조차 경기 영상을 못 올리게 하며 유튜브를 단속한 전례가 있다. 결론: 영상을 저장·재가공·호스팅하는 순간 즉시 침해. 남는 길은 '공식 채널 유튜브 임베드'뿐인데, 그 길은 유튜브 API 정책이 수익화를 막는다(다음 질문).

### Q3. 임베드만 하면 합법이라 치자. 그 앱으로 돈을 받을 수 있나?

사실상 없다. YouTube API 서비스 개발자 정책: (a) 임베드 플레이어의 콘텐츠 시청에 요금 부과 금지, (b) 재생 버튼 외의 행동(가입·구독 등)을 요구하는 접근 게이팅 금지, (c) YouTube API 데이터가 있는 화면에서 광고 판매 금지(유튜브 외 데이터가 그 화면에 독립적 가치를 줄 때만 예외), (d) 유튜브 광고 차단·오버레이 금지, (e) 다운로드·오프라인 금지, (f) 유튜브 핵심 경험을 복제하는 대체 서비스 금지(상당한 독립 가치가 있어야). 즉 구독·유료·광고 제거 셋 다 봉쇄되고, 광고는 일정·순위 같은 '비-유튜브 화면'에만 가능하다. 국내 판례도 확인: 대법원 2021도10903(전원합의체)은 침해 게시물 링크·임베드를 영리적·계속적으로 제공하면 공중송신권 침해 방조로 본다. 공식 채널 화이트리스트만 임베드하면 방조는 피하지만, 그 조건이 곧 '유튜브 정책 안에서만 놀라'는 뜻이다.

### Q4. '경쟁 공백'인가? 같은 앱이 이미 몇 개이고, 자금력 있는 사업자는 어떻게 됐나?

공백이 아니다. 플레이스토어에 KBO하이라이트, 하이라이트-프로야구 하이라이트, Korea Baseball Highlights, 야구픽(응원팀 하이라이트 자동 모아보기·찜·인기순 정렬), 프로야구 LIVE, 아구야구, 마이야구 등 동일 컨셉 인디 앱이 최소 5~7종이고 iOS에도 한국야구하이라이트가 있다(다운로드 수는 프록시 차단으로 미확인). 공식 진영은 KBO 앱·ruta·KBO STATS(스포츠투아이, 공식 기록 독점)와 티빙. 자금력 사례: LG유플러스 '스포키'는 개막 시즌 MAU 300만을 찍고도 수익화 실패로 2025년 3월 서비스 종료. 통신사도 못 만든 돈을 1인 개발자가 광고로 만든다는 가정은 근거가 없다.

### Q5. 유튜브보다 나은 점이 있다면, 그것은 유튜브 정책이 허용하는 것인가?

허용되는 차별화는 '팀 필터 + 새 영상 푸시 + 일정·스코어 병기' 정도인데, 이는 유튜브 알림 벨·티빙 팀 필터·야구픽이 이미 제공한다. 사용자가 진짜 원할 만한 것(광고 없이 보기, 오프라인 저장, 30초 요약, 자체 플레이어 연속 재생)은 전부 정책 위반이거나 저작권 침해다. 'LLM 요약'을 붙이는 각도는 40초 규정과 티빙 단속, 그리고 확정 교훈 (2) 'LLM만 붙이면 되는 아이디어 전멸'에 걸린다.

## 4. 수익모델 시나리오

### 1) 배너·네이티브 광고 (유일하게 정책상 가능, 단 일정·순위 등 비-유튜브 화면에만)

- **가격:** 무료 앱. 광고 노출은 영상 목록 화면이 아닌 경기 일정·순위·기록 화면 한정(YouTube API 정책: API 데이터 화면 광고 판매 금지 예외 요건 충족 필요)
- **월 수익 추정:** 보수: 시즌 중 DAU 300 × (10만원/1,000 DAU) × 광고 가능 화면 비중 50% ≈ 월 1.5만원, 비시즌 0 → 연평균 월 1만원. 현실: DAU 1,000 × 10~40만원/1,000 × 50% = 시즌 중 월 5~20만원, 연평균 월 3~13만원. 낙관: 인디 최상위 DAU 5,000 × 30~150만원/1,000 × 50% = 시즌 중 월 75~375만원, 비시즌 5개월 급감 → 연평균 월 45~220만원. 낙관 시나리오도 기존 5종 인디 앱과 트래픽을 나눠 가져야 하므로 도달 확률 낮음
- **근거:** 티빙·유튜브·KBO 앱이 무료라 유료 전환은 불가능하고, YouTube API 정책이 임베드 콘텐츠의 유료화·게이팅을 금지한다. 광고만 남는데 그마저 유튜브 데이터가 있는 화면에서는 팔 수 없어 노출 면적이 반토막. 스포키(MAU 300만) 폐업이 광고 모델의 한계를 실증

### 2) 일회성 '광고 제거' 인앱 결제 (회색 지대)

- **가격:** 3,900원 일회성 (한국 수용가 하한). 콘텐츠 접근은 그대로 두고 내 광고만 제거 — 유튜브 광고를 건드리지 않아야 함
- **월 수익 추정:** DAU 1,000 기준 MAU 약 3,000 × 결제 전환 1~3% = 월 30~90건 × 3,900원 × 스토어 수수료 85% ≈ 월 10~30만원(첫 시즌), 일회성이라 누적 후 급감. 웹 결제(수수료 0.8~3.4%)면 소폭 상승
- **근거:** 유튜브 정책상 '시청 요금'은 금지지만 '앱 자체 광고 제거'는 콘텐츠 게이팅이 아니라 해석 가능. 다만 광고가 없으면 남는 가치가 유튜브 알림과 동일해 지불 동기가 약함. 지불 증거 출처: 없음(추정치)

### 3) 제휴·어필리에이트 (티빙 가입 링크, 구단 굿즈·티켓 링크)

- **가격:** 티빙 신규 가입 CPA(제휴 프로그램 존재 여부·단가 미확인), 쿠팡파트너스 굿즈 링크 1~3%
- **월 수익 추정:** 보수 월 0~3만원, 현실 월 3~10만원, 낙관 월 20~40만원(DAU 5,000, 시즌 중). 시즌 개막·포스트시즌 직전 스파이크 후 소멸
- **근거:** 생중계는 유료(티빙)이므로 '하이라이트 보고 → 생중계 가입' 전환 링크는 자연스럽다. 그러나 CJ ENM이 개인 개발자에 제휴 단가를 열어줄 근거를 찾지 못했고, 쿠팡 굿즈 수수료는 트래픽 대비 미미

## 5. MVP 설계

**핵심 가설:** TVING SPORTS·KBO·구단 10개 공식 채널을 팀별 한 피드로 묶어 임베드로 보여주면, 야구 팬은 유튜브 구독·티빙 앱 대신 이 앱을 시즌 중 주 3회 이상 열고(D7 리텐션 30% 이상), 그 트래픽이 광고로 월 10만원 이상을 만든다 — 단, 리서치 결과 이 가설의 후반부(돈)는 정책상 거의 반증되었으므로 코드 전 검증만 권한다

**코드 전 검증:** 코드 0줄로 2주 실측: (1) TVING SPORTS·구단 채널 임베드를 팀별로 묶은 정적 웹페이지 1장(노션 또는 Carrd, 반나절)을 만들어 응원팀 갤러리·에펨코리아·더쿠에 '내 팀 하이라이트 한 페이지' 링크로 게시 → 2주간 클릭·재방문율(같은 IP 2회 이상) 측정, 재방문 20% 미만이면 드랍. (2) 그 페이지에 '광고 없는 앱 3,900원 사전예약' 가짜 버튼을 달아 클릭률 측정, 방문자 대비 2% 미만이면 유료 각도 드랍. (3) 기존 인디 앱 5종의 최신 리뷰 100개를 읽어 '불만'이 무엇인지 목록화 — 불만이 '광고·속도'뿐이면 차별화 불가로 판정. (4) 유튜브 API 정책 위반 여부를 Google 정책 가이드 체크리스트로 자체 점검하고, 애매하면 즉시 드랍. 이 4개 중 하나라도 실패하면 코드를 쓰지 않는다

**최소 기능:**
- 공식 채널 12개(티빙 스포츠, KBO, 구단 10) 화이트리스트를 YouTube Data API playlistItems.list(1유닛/호출) + WebSub(PubSubHubbub) 푸시로 수집
- 제목 규칙 파싱으로 '경기 하이라이트'만 분류 → 내 팀 필터 피드(날짜·상대팀·스코어 병기)
- YouTube IFrame Player 공식 임베드 그대로 재생(오버레이·자동재생·크기 정책 준수)
- 내 팀 새 하이라이트 업로드 시 웹 푸시(FCM) 1건
- 비-유튜브 화면(오늘 경기 일정·순위)에만 배너 1개

**뺀 것:**
- 영상 다운로드·오프라인 저장·자체 플레이어·광고 스킵(전부 정책 위반)
- 팬 업로드·커뮤니티 영상(2021도10903 방조 리스크, 화이트리스트 밖 금지)
- LLM 요약·자막·30초 컷(40초 규정+티빙 단속+'LLM만 붙이면' 교훈)
- 유료 구독·콘텐츠 게이팅(임베드 시청 요금 금지)
- KBO 기록·스탯 크롤링(공개 API 없음, 스포츠투아이 독점, DB권 리스크)
- 커뮤니티·댓글(콜드스타트, 24시간 모더레이션)
- iOS 앱 초기 출시(App Store 5.2.2 제3자 콘텐츠 리젝 리스크)

**개발 기간:** 약 3주 · **플랫폼:** 웹(PWA) 우선 — 스토어 심사 리스크(App Store 5.2.2, Play의 유튜브 제3자 클라이언트 정책) 회피와 웹 결제 수수료(0.8~3.4%) 이점. 실측 통과 시에만 플레이스토어 추가

## 6. 기술

- **스택:** Next.js 또는 SvelteKit(PWA) + Supabase 무료 티어(영상 메타·구독 설정) + YouTube Data API v3(playlistItems.list·videos.list, 1유닛/호출; search.list 100유닛은 사용 금지) + YouTube WebSub(PubSubHubbub) 채널 업데이트 푸시 + FCM/Web Push + YouTube IFrame Player API. 배포 Vercel 또는 Cloudflare Pages 무료
- **월 고정비:** 0~3만원 (도메인 연 1.5만원, Supabase·Vercel·FCM·YouTube API 무료 티어). DAU 5,000 도달 시 Supabase Pro 등 월 5~10만원. 법률 자문 1회 30~50만원 별도
- **어려운 부분:**
  - 12개 채널 영상 중 '경기 하이라이트'만 정확히 분류: 구단마다 제목 포맷이 다르고 예고·인터뷰·쇼츠가 섞임. 제목 규칙이 바뀌면 피드가 깨짐
  - YouTube API 정책 준수 설계: 임베드 플레이어 최소 크기·오버레이 금지·유튜브 광고 비차단·API 데이터 화면 광고 금지·데이터 보관 기간을 코드 수준에서 지켜야 하며, 감사 시 증빙 필요
  - 쿼터 관리: 기본 10,000유닛/일. 12채널×10분 폴링=약 1,700유닛으로 충분하나, 사용자별 조회 기능을 넣는 순간 초과. 확장 시 컴플라이언스 감사(수 주 소요, 집계형 앱은 거절 빈번)
  - WebSub 구독 리스(약 10일) 자동 갱신과 실패 시 폴링 폴백
  - 경기 종료 직후(22~23시) 전 팀 동시 업로드 트래픽 스파이크와 푸시 지연 CS
  - 저작권 화이트리스트 무결성: 공식 채널 외 영상이 한 건이라도 섞이면 2021도10903 방조 리스크

## 9. 적대적 검증 — 회의론자의 반박

**판정: 보류/드랍** — 분석가의 '보류/드랍' 판정은 옳으며, 반증 작업은 오히려 사망 근거를 더 늘렸다. 핵심 전제(티빙 비회원 무료 하이라이트, KBO X TVING 유튜브 전 경기 매일 업로드, 2031년까지 연 900억 독점, YouTube API의 광고·유료화 금지 조항, 인디 앱 5종 존재, 대법원 2021도10903)는 전부 검색으로 확인됐다. 다만 분석 내부에 결함이 있다: 스포키 폐업은 '광고 수익화 실패'가 아니라 중계권 상실 후 트래픽 증발이 원인이고, '광고 제거' 결제 추정은 일회성 결제에 매월 MAU 전환율을 곱한 산술 오류이며, 광고 가능 화면 50%는 근거가 없고, 권리자가 YouTube Studio에서 '앱 내 임베드 차단'을 한 번 켜면 끝나는 킬스위치가 누락됐다. 가장 큰 결함은 피벗안이다. 디지털 리캡 카드는 직관로그·승리지쿄·승요·승요일기·Ballog·하루1루·직꾸 등 10종 이상의 무료 앱이 이미 시즌 승률 카드 공유를 제공해 즉사하고, 인쇄 포토북은 시즌 종료가 구매를 강제하는 데드라인이 아니며 스냅스·퍼블로그·포토몬 DIY가 선점했고 '외주 인쇄 API'와 '모바일 청첩장의 인쇄 파이프라인 재활용'은 실재하지 않는 가정이다. 원본과 피벗 모두 드랍하고 현역 라인업(논문서식·청첩장·현장견적)에 시간을 쓰는 것이 맞다.

### 반박 1 [약함]

- **주장:** LG유플러스 스포키는 'MAU 300만에도 수익화 실패로 폐업' → 스포츠 팬 플랫폼은 트래픽이 나와도 광고로 돈이 안 된다는 국내 실증
- **반박:** 인과가 다르다. 뉴시스·디지털데일리·한경(2025.1) 보도상 종료 배경은 (a) 2024년 뉴미디어 중계권이 티빙으로 넘어가 생중계를 잃은 뒤 이용빈도 급감, (b) LGU+의 'AI 집중' 경영 기조다. 2024년 4월 MAU 300만은 중계권 상실 후 '편파 해설' 등으로 버틴 수치고 그 뒤로 하락했다. 즉 스포키는 '광고 모델의 한계' 증거가 아니라 '권리 없는 스포츠 플랫폼은 트래픽 자체가 증발한다'는 증거다. 결론(드랍)은 오히려 강화되지만, 분석가가 인용한 논리는 틀렸다.

- **주장:** 일회성 '광고 제거' 3,900원: DAU 1,000 → MAU 3,000 × 결제 전환 1~3% = 월 30~90건 → 첫 시즌 월 10~30만원
- **반박:** 산술 오류. 일회성 결제인데 '매월 MAU 전체'에 전환율을 곱했다. 일회성 결제의 월 매출은 '해당 월 신규 유입 × 전환율'이어야 하며, MAU 3,000 중 재방문자는 이미 샀거나 안 산 사람이다. 첫 달만 30~90건이고 그 뒤로는 신규 유입(수십~수백 명) × 1~3% = 월 수 건 수준으로 즉시 붕괴한다. 또한 앱의 유일한 콘텐츠가 유튜브 영상인 상황에서 '광고 제거' 결제는 실질적으로 임베드 시청 경험에 대한 과금으로 해석될 여지가 있어(분석가 스스로 '회색 지대'라 인정) 이 라인 전체가 정책 리스크 위에 서 있다. 낙관 시나리오 상한(연평균 월 220만원)은 이 두 오류를 빼면 더 내려간다.

- **주장:** 광고는 일정·순위 등 '비-유튜브 화면'에 걸면 되고, 광고 가능 화면 비중은 50%
- **반박:** 50%는 근거 없는 가정이다. YouTube API 개발자 정책 원문은 'API 데이터가 있는 페이지/화면에서 광고·스폰서십·프로모션 판매 금지, 단 유튜브 데이터를 제거해도 그 판매를 정당화할 만큼 독립적 가치가 있는 비-유튜브 콘텐츠가 같은 화면에 있을 때만 예외'다. 이 앱의 존재 이유가 '하이라이트 피드'이므로 사용자 체류 대부분은 영상 목록·재생 화면(API 데이터 포함)에 몰리고, 일정·순위 화면은 네이버·KBO 앱·티빙이 더 잘 제공해 사용자가 머물 이유가 없다. 실제 광고 노출 가능 체류 비중은 50%가 아니라 10~20%대로 보는 것이 합리적이며, '독립적 가치' 판단은 구글 재량이라 통과 보장도 없다. 광고 시나리오 전부를 절반 이하로 다시 깎아야 한다.

### 반박 6 [약함]

- **주장:** solo_feasibility 6점, 3주 빌드, PWA 우선 출시로 스토어 리스크 회피
- **반박:** PWA의 핵심 가치가 '내 팀 새 영상 푸시'인데 iOS PWA 푸시는 홈 화면 추가를 거쳐야만 동작해(iOS 16.4+) 국내 iOS 사용자층에서 '알림이 안 와요' CS가 구조적으로 발생한다. iOS 네이티브로 가려 해도 Apple 개발자 포럼에 유튜브 임베드·가이드라인 준수 상태에서도 5.2.2/5.2.3으로 리젝되고 '제3자 콘텐츠 표시 권한 서류'를 요구받은 사례가 다수 확인된다(티빙·KBO가 서류를 써줄 리 없다). 즉 절반의 사용자층에서 핵심 기능이 반쪽이거나 진입 자체가 막힌다. 판정을 바꾸진 않지만 6점은 후하다.

### 반박 7 [결정적]

- **주장:** 피벗: '디지털 시즌 리캡 카드' 건당 3,900원
- **반박:** 무료 선점자가 이미 10종 이상이다. 직관로그(티켓 형태 자동 저장·승률 차트), 승리지쿄(승률 캐릭터 카드 공유), 승요, 승요일기, 야구일기 Ballog('승요/패요' 카드 공유), 하루1루(승률·구장별·월별 차트), 직꾸, 야구보구, 직관일기-야구, 승리요정 — 전부 무료로 시즌 승률·전적 카드를 만들어 공유하게 해준다. 2025시즌부터 SNS에서 '직관 기록 앱 뭐 쓰냐'가 일상 대화일 만큼 습관성·무료 카테고리로 굳어졌다. 확정 교훈 (1) '경쟁 공백은 허위'와 (5) '무료 대체재에 즉사'에 정확히 걸린다. 디지털 카드 3,900원은 출시 전에 사망.

### 반박 8 [강함]

- **주장:** 피벗: '직관 시즌 리캡 인쇄 포토북' 건당 1.9~2.9만원 — 데드라인 이벤트 × 건별 결제, 인쇄는 외주 API, 청첩장 라인업의 디자인·결제·인쇄 파이프라인 재활용
- **반박:** 네 군데가 무너진다. (a) '데드라인'이 아니다: 결혼식·논문 제출과 달리 시즌 종료는 구매를 강제하지 않는다. 포토북은 11월에도 1월에도 만들 수 있으므로 생존 공식의 핵심인 '기한이 만드는 지불 압력'이 없다. (b) 선점자: 스냅스·퍼블로그·포토몬(아이돌 팬북 DIY 전용 카테고리 보유)·북토리·레드프린팅·스탑북이 이미 사진만 올리면 되는 DIY 포토북을 제공하고, 야구 팬용 '템플릿'만 얹은 재판매업은 마진이 인쇄사에 흡수된다. 전문 앱들도 '티켓 형태 자동 저장'까지 이미 한다. (c) '인쇄 외주 API'는 미검증 가정: 국내 포토북 사업자가 개인 개발자에게 여는 주문 API·B2B 파이프라인의 존재 근거를 검색에서 찾지 못했다(킨코스 B2B는 기업 후불 계약 대상). 없으면 주문마다 사람이 파일을 넘기는 수작업 = '매일 갈아넣는 구조'. (d) 청첩장 라인업은 '모바일' 청첩장이라 인쇄 파이프라인이 애초에 없다. 재활용 주장은 허위. 덤으로 구단 휘장·엠블럼·마스코트 상표권은 KBO가 위임 관리하므로 템플릿에 못 쓰고(팀 컬러 정도만 가능해 '감성'이 반감), 선수 얼굴을 크게 인쇄하는 상품은 퍼블리시티권(부정경쟁방지법 타목) 회색지대다.

### 반박 9 [약함]

- **주장:** 취소표 알림 각도는 '2025년부터 예매처가 정식 취소표 대기 기능 운영'이라 사망
- **반박:** 근거 출처가 개인 블로그(컴변스CLS 등)뿐이며 인터파크·티켓링크 공식 공지로는 확인하지 못했다. 다만 이 각도는 예매처 약관·매크로 규제·CS 부담 때문에 어차피 1인 실행 부적합이므로 사망 판정 자체는 유지된다. 출처 품질만 지적한다.

### 치명적 결함

- 공식·무료 대체재가 이미 완전하다: 티빙은 2024년 출범 정책부터 하이라이트·다시보기를 비회원 무료로 열었고(한경 2024.3), 'KBO X TVING' 유튜브 채널이 전 경기 하이라이트를 매일 올리며, KBO 앱이 7일치를 무료 제공한다. 원본의 '구단 채널마다 흩어져 귀찮다'는 전제 자체가 오진.
- 권리자가 세 겹의 킬스위치를 쥐고 있다: (1) YouTube Studio의 '앱 내 임베드 차단' 설정 한 번, (2) 유튜브 업로드 정책 변경, (3) 구글의 API 키·프로젝트 정지. 2031년까지 연 900억을 내는 CJ ENM이 무임승차 앱을 인지하면 코드 변경 없이 즉시 빈 화면이 되고, 2019년 KBO 저작권보호팀 단속 전례상 방치 확률은 낮다.
- 정책상 허용되는 수익 모델이 없고, 그나마의 추정도 산술 오류로 부풀려졌다: 임베드 시청 유료화·게이팅 금지, API 데이터 화면 광고 판매 금지(독립 가치 예외는 구글 재량). '광고 제거' 결제는 일회성인데 MAU에 매월 전환율을 곱했고, 광고 가능 화면 50%는 근거 없다. 현실적 상한은 시즌 중 월 수만원.
- 동일 컨셉 인디 앱이 이미 다수(KBO하이라이트, 하이라이트-프로야구 하이라이트, 야구픽(응원팀 하이라이트 자동 모아보기·찜·인기순), 프로야구 LIVE, iOS 한국야구하이라이트)이며 전부 배너 광고로 연명한다. '경쟁 공백'은 허위.
- 피벗안(직관 시즌 리캡)도 죽는다: 디지털 카드는 직관로그·승리지쿄·승요·승요일기·Ballog·하루1루·직꾸·야구보구 등 10종 이상 무료 앱이 선점, 인쇄 포토북은 데드라인이 없고(생존 공식 미충족) 스냅스·퍼블로그·포토몬이 DIY로 선점했으며, '외주 인쇄 API'와 '청첩장 인쇄 파이프라인 재활용'은 존재하지 않는 가정이다.

### 진행 조건 (굳이 살리려면)

1. 원본(하이라이트 모아보기)은 조건부 진행 자체가 성립하지 않는다. 티빙·KBO로부터 서면 임베드/집계 허가를 받는 경우에만 재검토 — 1인 개발자에게 현실적으로 불가능하므로 사실상 드랍.
2. 피벗(인쇄 포토북)을 굳이 살리려면 코드 전 세 가지를 '문서'로 먼저 확인: (1) 국내 인쇄사 중 개인 사업자에게 주문 API 또는 자동 발주(파일 업로드→인쇄→배송) 계약을 열어주는 곳의 실명·단가·최소 수량, (2) 구단 로고·엠블럼·마스코트를 일절 쓰지 않은 팀 컬러 기반 샘플 3종으로 응원팀 갤러리·인스타에서 2주 사전주문 실측(실결제 10건 미만이면 드랍, 클릭률이 아니라 결제), (3) 선수 초상이 들어간 상품을 팔지 않는다는 원칙과 이용약관 초안.
3. 위 (1)이 없으면 주문마다 수작업 발주가 되어 '매일 갈아넣는 구조'에 해당하므로 즉시 드랍하고 야구 도메인을 접는다.
4. 분석가의 수치 인용은 재사용 전 시점 확인 필요: 2025 최종 관중 1,231.3만(1,201.9만은 9/27 중간치), 티빙 5년 연장은 2025.11 우선협상 타결 후 2026.8 정식 계약 발표.

## 참고: 심사위원의 라인업 비교 의견 (발상자 판단으로 라인업은 폐기됨)

현역 라인업(1위 논문서식 클리닉 → 2위 감성 모바일 청첩장 → 3위 현장견적)은 바꾸지 않는다. 숫자 비교: 두 신규 아이디어의 회의론자 조정 후 기대 수익은 AR 러닝 피벗이 월 30~35만원(분기 1회 이벤트 150명 전제, 채널 자산 없음), 야구 하이라이트가 연평균 월 3~13만원(권리자 킬스위치 1회로 0원)이다. 반면 논문서식 클리닉은 건당 9,900~19,900원에 '제출 마감'이라는 유저 소유 데드라인이 있어 결제 전환 1~3% 벤치마크에서도 월 방문 1,000명이면 건당 15,000원 기준 15~45만원이 되고, 그것도 스토어 수수료 없이 웹 결제 0.8~3.4%로 받는다. 청첩장은 실판매가 1.5~2.5만원이 이미 검증된 시장이다. 즉 신규 2개의 '낙관' 케이스가 현역 1·2위의 '보수' 케이스와 겹치는 수준이고, 리스크 프로필은 정반대다(신규: 권리자·선점자 즉사 가능 / 현역: 유저 소유 콘텐츠·법적 봉쇄 없음). 시점 근거도 있다: 오늘이 9월 3일이므로 2학기 학위논문 제출(10~12월)과 가을 결혼 성수기가 2~3개월 앞에 있어, 현역 1·2위의 2주 실측을 지금 돌리지 않으면 올해 데드라인 수요를 통째로 놓친다. 3위 현장견적은 리서치 보강 조건이 그대로 유지되며, 두 신규 아이디어는 3위 아래 '2군'에도 넣지 않고 탈락 처리한다 — 2군에 두면 발상자가 자꾸 돌아보는 비용이 생기는데, 두 건 모두 '조건 충족 시 부활'이 아니라 '도메인 자체가 구조적으로 닫힘'이기 때문이다.
