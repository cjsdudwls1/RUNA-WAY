# 배경음악 규격

- 파일 4개. 없으면 조용히 넘어간다. 일부만 넣어도 된다
- 앱은 홈 화면에서 크게, 달릴 때는 작게(동물 소리가 먼저 들리게) 반복 재생한다
- 설정 > 배경음악에서 끌 수 있다

## 파일

| 파일 | 장면 | 분위기 |
|---|---|---|
| animal_home.mp3 | 동물 사파리 홈 | 사바나 탐험 다큐멘터리 오프닝. 아프리카 타악기, 마림바, 칼림바. 밝고 모험적 |
| animal_run.mp3 | 동물 사파리 달리기 | 타악기 위주 그루브. 170 BPM 전후(달리기 발걸음 박자). 선율은 거의 없이 |
| monster_home.mp3 | 괴물 추격 홈 | 한밤의 괴담. 대금이나 해금의 음산한 선율, 낮은 드론. 게임 같은 괴물 느낌(진짜 공포 영화 말고) |
| monster_run.mp3 | 괴물 추격 달리기 | 긴장감 있는 드론 + 북, 장구 리듬. 170 BPM 전후 |

## 규격

| 항목 | 값 |
|---|---|
| 형식 | mp3, 스테레오, 44.1kHz, 128kbps |
| 길이 | 60~120초. 끝과 처음이 이어져 끊김 없이 반복되게(마지막 마디가 첫 마디로 자연스럽게) |
| 음량 | 통합 약 -18 LUFS, 피크 -1dB |
| 보컬 | 없음. 말소리는 동물 소리, 괴물 대사와 겹친다 |
| 달리기용 두 곡 | 800Hz~3kHz를 비워 둔다(악기를 적게). 이 대역에 동물 소리와 대사가 있다 |
| 크기 | 곡 하나 2MB 이하 |

## 만드는 법

- 1순위: 음악 생성 모델 ACE-Step (Apache-2.0, 로컬 GPU). 결과물 상업 이용 가능
- 2순위: 상업 이용 가능한 무료 곡. Pixabay Music(Pixabay 라이선스), OpenGameArt(CC0, CC-BY), freesound(CC0, CC-BY)
- 금지: MusicGen(가중치가 비상업 라이선스), 저작권 곡, 유튜브 추출, NC, ND

## 출처 기록

- `web/music/credits.json`. 형식은 web/sounds/README.md의 credits.json과 같다(animal, kind 칸은 장면 이름으로)
- 빌드가 동물 소리 출처와 합쳐 출처 페이지(credits.html)를 만든다

## 확인

- `python3 web/build.py` 후 `python3 -m http.server -d docs/app 8000`
- 홈 화면을 한 번 누르면 홈 음악, 출발하면 달리기 음악으로 바뀐다
- 반복 이음새에서 "툭" 끊기는 소리가 없는지 들어본다
